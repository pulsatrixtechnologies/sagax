# Sagax 0.8.56

Deuxième correctif rapide de la journée. La pastille du bot reprend sa taille et tient sur une seule ligne « Nom · Titre », le texte du thème sombre s'adoucit pour coller à Grok Bot, et le menu de profil prend l'ordre et le look de Grok Bot. Les runs de routine se lisent comme des messages normaux, la section Coding s'aligne sur ses voisines avec une vraie durée, la page du bot se réorganise, et Grok ne refuse plus un tour à cause d'une connexion MCP hors sélection. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

## Chat

* La pastille d'en-tête du bot passe à 40 px partout (chat, Coding) et affiche « Nom · Titre » sur une seule ligne, comme avant. PR #2303, PR #2305.
* Le composer montre la ligne de limite d'usage ; le clic droit ouvre le menu Ordinateur ; en mode unifié, les liens de conversation et les puces « aller au groupe » disparaissent ; le bas du chat gagne un fondu. PR #2294.
* Les runs de routine s'affichent comme des messages normaux du bot, avec un en-tête de routine sur une seule rangée. PR #2283.
* Le bouton GIF du composer a exactement le même look que le « + ». PR #2307.
* Le menu Effort du modèle, quand le bot travaille, ne montre plus que la rangée Effort, sans lignes d'aide. PR #2309.

## Apparence

* Thème sombre : l'encre du texte passe de #f5f5f5 à #e4e4e7 (texte, barre latérale, bulles), et le texte secondaire à #9e9ea3, avec un contraste conforme. Même rendu que Grok Bot. PR #2303.

## Menu de profil

* Le menu du profil suit Grok Bot : la rangée du forfait d'abord, puis un sous-menu Aide (Centre d'aide, Raccourcis clavier, Notes de version, Vérifier les mises à jour, Envoyer un commentaire, À propos), en 260 px de large avec des rangées de 36 px. PR #2302.

## Coding

* La section Coding a le même look que ses voisines et affiche la vraie durée d'une session (le serveur part du début du dernier tour : fini les « 228h 06m »). PR #2281.
* L'en-tête d'une session de code utilise la pastille du bot ; les détails `</>` passent dans le panneau du bot sous la carte « Cette session ». PR #2290.

## Page du bot

* La page du bot met l'en-tête Apparence en haut et range ses 4 onglets en deux colonnes qui s'adaptent à la largeur. PR #2284.
* Le choix « Qui paie » revient pour les bots partagés. PR #2292.

## Réglages

* La section Auto est refaite en rangées dans une seule carte. PR #2300.
* **Lier à Grok Bot** (ancien « Linked Grok ») se range sous Fournisseurs > Avancé. La section Avancé suit l'UX des Réglages, sans carte dans une carte ; la recherche la retrouve. PR #2307.
* **Mèmes / GIPHY** : une rangée compacte ; la saisie de la clé n'apparaît que derrière « Changer la clé » quand une clé existe. PR #2307.
* **Appels téléphoniques** : un seul titre ; l'état On/Off passe dans la ligne grise comme les voisines, et le numéro de rappel a sa propre rangée. PR #2310.
* **Voix > Avancé** : des rangées au lieu d'une carte dans une carte ; Live call et Chatterbox en replis standard, l'état Off d'organisation en état standard. PR #2310.
* Tous les replis bruts et les listes déroulantes natives des Réglages et du panneau du bot (moteurs, comptes Claude/Codex, domaine, Chrome, contrôle du Mac, équipes, mémoire, skills, courriel, MCP, serveur perso, cache de prompt…) passent aux replis et pilules standard, sans retirer d'info. PR #2310.

## Moteurs

* **Grok** : un tour n'est plus refusé à cause d'une connexion MCP native qui n'est pas dans la sélection du bot. PR #2289.

## Sous le capot

* Tests de garde et tests du chat réparés sur la branche du cycle, sans changement visible. PR #2293, PR #2297.

## Avant de mettre à jour

Installe cette version sur le serveur Sagax, puis mets à jour l'app de bureau et l'app iOS. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés.

* Lier à Grok Bot se trouve maintenant sous Réglages > Fournisseurs > Avancé.

## English

Second quick fix release of the day. The bot pill gets its size back and fits "Name · Title" on one line, dark theme text is softened to match Grok Bot, and the profile menu takes Grok Bot's order and look. Routine runs read as normal messages, the Coding section matches its neighbours with a real duration, the bot page is reorganized, and Grok no longer refuses a turn over an MCP connection outside the selection. It covers the desktop app, the server, iPhone and iPad.

### Chat

* The bot header pill is 40 px everywhere (chat, Coding) and shows "Name · Title" on one line, as before. PR #2303, PR #2305.
* The composer shows the usage limit line; right-click opens the Computer menu; in unified mode, conversation links and "go to group" chips are gone; the bottom of the chat fades out. PR #2294.
* Routine runs show as normal bot messages, with a one-row routine header. PR #2283.
* The composer GIF button looks exactly like the "+". PR #2307.
* The model Effort menu, while the bot works, shows only the Effort row, with no help lines. PR #2309.

### Appearance

* Dark theme: text ink moves from #f5f5f5 to #e4e4e7 (text, sidebar, bubbles), and secondary text to #9e9ea3, with compliant contrast. Same look as Grok Bot. PR #2303.

### Profile menu

* The profile menu follows Grok Bot: the plan row first, then a Help submenu (Help Center, Keyboard shortcuts, Release notes, Check for updates, Send feedback, About), 260 px wide with 36 px rows. PR #2302.

### Coding

* The Coding section matches its neighbours and shows a session's real duration (the server starts from the last turn: no more "228h 06m"). PR #2281.
* A coding session header uses the bot pill; the `</>` details move to the bot panel under the "This session" card. PR #2290.

### Bot page

* The bot page puts the Appearance header at the top and lays its 4 tabs in two columns that adapt to the width. PR #2284.
* The "Who pays" picker is back for shared bots. PR #2292.

### Settings

* The Auto section is rebuilt as rows in a single card. PR #2300.
* **Link with Grok Bot** (formerly "Linked Grok") lives under Providers > Advanced. The Advanced section follows the Settings UX, with no card inside a card; search finds it. PR #2307.
* **Memes / GIPHY**: a compact row; the key field only shows behind "Change key" once a key is saved. PR #2307.
* **Phone calls**: one title; On/Off moves into the grey line like the neighbours, and the callback number has its own row. PR #2310.
* **Voice > Advanced**: rows instead of a card inside a card; Live call and Chatterbox are standard folds, the organization Off is a standard status. PR #2310.
* Every raw fold and native dropdown in Settings and the bot panel (engines, Claude/Codex accounts, domain, Chrome, Mac control, teams, memory, skills, mail, MCP, personal server, prompt cache…) moves to the standard folds and pills, without dropping information. PR #2310.

### Engines

* **Grok**: a turn is no longer refused because of a native MCP connection that is not in the bot's selection. PR #2289.

### Under the hood

* Guard tests and chat tests fixed on the cycle branch, with no visible change. PR #2293, PR #2297.

## Before you update

Install this version on the Sagax server, then update the desktop and iOS apps. Your bots, models, teams, plugins and personal settings are kept. Link with Grok Bot now lives under Settings > Providers > Advanced.
