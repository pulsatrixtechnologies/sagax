# Sagax 0.8.57

Correctifs de régression. Un seul menu de modèle partout, le menu de profil revient comme avant, le chat défile sous la pastille du bot, et un nouveau sujet reçoit de nouveau les rapports de routine et les messages entre bots. L'écran de l'ordinateur s'affiche enfin dans la fenêtre Watching, un mème GIF n'est plus refusé, et les jetons spéciaux d'un modèle ne fuient plus dans les réponses. Le panneau de groupe et la page du bot se réorganisent. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

## Chat

* **New topic** : le sujet est créé sur le serveur dès qu'on l'ouvre, donc il reçoit les rapports de routine, les messages entre bots et les notifications au lieu de les laisser dans l'ancien sujet. PR #2316.
* Le chat d'un bot ou d'un groupe défile sous la pastille, qui flotte par-dessus avec un léger fondu ; la rangée « Ajouter des instructions de groupe » quitte le haut du chat de groupe (l'édition reste dans le panneau du groupe). PR #2343.
* Les jetons spéciaux d'un gabarit de chat (par exemple `<|eos|>`) ne s'affichent plus comme texte de réponse, même coupés entre deux morceaux du flux. PR #2350, PR #2353.
* En groupe, le bouton du mode vocal est caché (le micro reste) et le bouton de relance prend le style standard. PR #2322.
* Un mème GIF n'est plus refusé comme un fichier du serveur par la garde de sécurité. PR #2346.

## Modèles

* Un seul menu de modèle partout : Réglages > Modèles, « Choisir le modèle pour n bots » et Bot > Modèle affichent le même menu que la barre du chat ; le mode à deux colonnes disparaît. PR #2356.

## Menu de profil

* Le menu de profil revient comme avant la refonte de 0.8.56, sur le bureau et sur iPad. PR #2341, PR #2352.

## Ordinateur

* L'écran de cet ordinateur s'affiche dans la fenêtre Watching / You have control, au lieu de chercher la capture d'une VM locale absente. PR #2344.
* La carte Ordinateur gagne un bouton « ... » qui ouvre le même menu que le clic droit, dans le panneau du bot et celui du groupe. PR #2359.

## Panneau de groupe

* L'onglet Activité suit l'ordre du panneau du bot : À venir, Suggéré, Ordinateur, Tâches, puis Coding, Activité et Sessions à distance par bot ; l'Ordinateur devient une section avec la carte du bot. PR #2326, PR #2333.
* Les onglets Instructions et Mémoire sont cachés du panneau de groupe ; la mémoire de groupe reste active par défaut. PR #2326.

## Page du bot

* L'en-tête de la page d'édition du bot devient la grande carte de la mascotte (nom en 28 px, libellé, Jouer un mouvement), avec le X et Privé qui restent visibles au défilement, sans retirer d'info. PR #2324.
* La bannière couleur de la mascotte revient en haut de la page, la carte héros chevauche son bord bas. PR #2338.

## Routines

* Une routine dans le panneau de droite n'a plus qu'un seul volet, partagé par le panneau du bot et celui du groupe : instruction modifiable sur place, une seule rangée « Quand exécuter ». PR #2318.
* Le menu de fréquence s'ouvre vers le haut au lieu de couvrir Annuler, et la bascule Active réagit tout de suite (retour arrière si la requête échoue). PR #2330.
* À venir > Nouveau dossier… montre le dossier créé, même vide. PR #2348.

## Plugins

* Les connecteurs des comptes de moteur (Claude, xAI, ChatGPT) deviennent des rangées de plugins, une section « De <fournisseur> » chacune, dans la recherche, les filtres et le compte des connectés. PR #2323.
* Les skills privés s'affichent en deux colonnes, comme Installés. PR #2328.

## iPad

* La pastille du bot tient sur une seule ligne « Nom · Titre » et l'encre du thème suit le bureau. PR #2339.

## Sous le capot

* Le serveur est découpé en modules plus petits, sans changement visible. PR #2331.
* Tests de base et gardes réparés (dont une règle Toujours permettre des outils de fournisseur après le découpage), texte de « quitter le groupe » réécrit. PR #2319, PR #2334, PR #2357.

## Avant de mettre à jour

Installe cette version sur le serveur Sagax, puis mets à jour l'app de bureau et l'app iOS. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés.

## English

Regression fixes. One model menu everywhere, the profile menu is back as before, the chat scrolls under the bot pill, and a new topic again receives routine reports and bot-to-bot messages. This computer's screen finally shows in the Watching window, a GIF meme is no longer refused, and a model's special tokens no longer leak into replies. The group panel and the bot page are reorganized. It covers the desktop app, the server, iPhone and iPad.

### Chat

* **New topic**: the topic is created on the server as soon as it opens, so it receives routine reports, bot-to-bot messages and notifications instead of leaving them in the previous topic. PR #2316.
* A bot or group chat scrolls under the pill, which floats over it with a light fade; the "Add group instructions" row leaves the top of the group chat (editing stays in the group panel). PR #2343.
* Chat template special tokens (such as `<|eos|>`) no longer show as reply text, even when split across two stream chunks. PR #2350, PR #2353.
* In a group, the voice mode button is hidden (the mic stays) and the nudge button uses the standard style. PR #2322.
* A GIF meme is no longer refused as a server file by the safety guard. PR #2346.

### Models

* One model menu everywhere: Settings > Models, "Set model for n bots" and Bot > Model show the same menu as the chat bar; the two-column mode is gone. PR #2356.

### Profile menu

* The profile menu is back as it was before the 0.8.56 redesign, on desktop and iPad. PR #2341, PR #2352.

### Computer

* This computer's screen shows in the Watching / You have control window, instead of looking for a capture from a missing local VM. PR #2344.
* The Computer card gets a "..." button that opens the same menu as right click, in the bot panel and the group panel. PR #2359.

### Group panel

* The Activity tab follows the bot panel order: Upcoming, Suggested, Computer, Tasks, then Coding, Activity and Remote sessions per bot; Computer becomes a section with the bot's card. PR #2326, PR #2333.
* The Instructions and Memory tabs are hidden from the group panel; group memory stays on by default. PR #2326.

### Bot page

* The bot edit page header becomes the large mascot card (name at 28 px, label, Play a move), with X and Private kept visible while scrolling, without dropping any information. PR #2324.
* The mascot colour banner is back at the top of the page, with the hero card overlapping its bottom edge. PR #2338.

### Routines

* A routine in the right panel has a single pane, shared by the bot panel and the group panel: instruction editable in place, one "When to run" row. PR #2318.
* The frequency menu opens upward instead of covering Cancel, and the Active toggle reacts at once (rolled back if the request fails). PR #2330.
* Upcoming > New folder… shows the created folder, even when empty. PR #2348.

### Plugins

* Engine account connectors (Claude, xAI, ChatGPT) become plugin rows, one "From <provider>" section each, in search, filters and the connected count. PR #2323.
* Private skills show in two columns, like Installed. PR #2328.

### iPad

* The bot pill fits "Name · Title" on one line and the theme ink follows the desktop. PR #2339.

### Under the hood

* The server is split into smaller modules, with no visible change. PR #2331.
* Base tests and guards repaired (including an Always allow rule for provider tools after the split), "leave group" copy rewritten. PR #2319, PR #2334, PR #2357.

### Before you update

Install this version on the Sagax server, then update the desktop app and the iOS app. Your bots, models, teams, plugins and personal settings are kept.
