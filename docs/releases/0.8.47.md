# Sagax 0.8.47

Une routine appelée par son nom roule. Avant chaque run d'une routine Pulsatrix Flow, Sagax ne lance plus de vérification Flow à blanc : une phrase ordinaire du texte de la routine ne peut plus être prise pour un nom de recette et bloquer le run.

* La vérification Flow à blanc reste offerte par le bouton « Vérifier la routine », seulement quand vous la demandez.
* Les autres vérifications avant un run (moteur connecté, crédits, ordinateur en ligne) ne changent pas.

## Avant de mettre à jour

Installez cette version sur le serveur Sagax. Les routines et leurs horaires sont conservés. Rien à configurer.

## English
<!-- date: 2026-11-05 -->

A routine called by name runs. Before each run of a Pulsatrix Flow routine, Sagax no longer starts a Flow dry check: an ordinary sentence of the routine's text can no longer be taken for a recipe name and block the run.

* The Flow dry check is still offered by the “Check routine” button, only when you ask for it.
* The other checks before a run (engine signed in, credits, computer online) are unchanged.

## Before updating

Install this version on the Sagax server. Routines and schedules are preserved. Nothing to configure.
