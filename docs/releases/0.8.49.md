# Sagax 0.8.49

Cette version corrige les rôles dans le chat et ajoute la largeur du chat, les artefacts Claude et le partage de la bibliothèque d'un bot. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

### Rôles

* La zone d'écriture n'a plus de sélecteur de rôle « Agir comme ». Le champ « Au nom de » d'une routine paraît seulement pour une routine qui roule une recette Pulsatrix Flow. Issue #2032.
* Le chat ne montre plus aucun rôle, sur le bureau, le web et iOS : ni pastille de rôle sur les étapes d'outil, ni carte « Agit comme », ni avis de changement de rôle. L'onglet Rôles du panneau du bot reste là pour voir les rôles utilisés et les permissions manquantes. Issue #2033.
* L'avis de limite d'utilisation du moteur a un bouton Fermer et reste fermé. Issue #2033.

### Chat

* Largeur du chat : Réglages > Conversation offre Lecture (colonne étroite), Large ou Pleine largeur, pour les conversations, les salles et le travail de code. Issue #2004.
* Artefacts Claude : quand un bot Claude publie une page claude.ai avec votre propre compte Claude, une carte la montre dans le chat, avec ses commentaires, sur le bureau et sur iOS. Une carte de consentement paraît avant une publication quand le compte du moteur n'est pas le vôtre. Issue #2018.
* Une étape Codex dont l'appel MCP échoue montre le vrai message du serveur au lieu de « aucun message d'erreur ». Issue #1988.
* Le menu des modèles ouvert seul reste dans la fenêtre, et la visite guidée saute l'étape Ordinateur quand elle n'a rien à montrer. Issues #1979 et #2000.

### Bibliothèque et Capacités

* Un bot partagé partage aussi ses Liens, Médias et Fichiers avec les personnes du partage, y compris la conversation principale. Les fils confidentiels restent exclus et l'export reste au propriétaire.
* Dans la console Perspicax, les Capacités d'un bot sont celles de son propriétaire, et non celles de la personne qui regarde. Issue #2029.

### Routines

* Une routine peut choisir son niveau de raisonnement à côté de son modèle, sans changer le chat. Issue #1999.
* « A besoin de son ordinateur » se règle aussi par les outils du bot, et une carte de proposition de routine ouverte paraît dans les approbations en attente. Issue #1996.
* Quand le moteur principal refuse un run, la vérification note le moteur de relève prêt, et les skills Flow de l'organisation suivent sur le moteur de relève.

### Coût et vitesse

* Claude charge moins d'outils au départ : les outils rares attendent derrière la recherche d'outils, ce qui allège chaque appel.
* Changer de fil annule les mises au chaud MCP qui attendaient encore. Issue #1975.
* Codex garde son processus app-server d'un tour à l'autre dans un même fil, au lieu d'en démarrer un neuf à chaque message. Issue #1969.

### Autres correctifs

* Une adresse de serveur compatible OpenAI collée avec /chat/completions garde la bonne adresse de base au lieu de finir en 404. Issue #2022.
* Le bot ne prend plus une référence de paquet npm pour une adresse courriel. Issue #2028.
* Claude Code 2.1.318 est la version épinglée.
* Le code interne utilise un seul helper partagé par besoin (tailles de fichier, JSON canonique, description d'approbation). Issue #1382.

## Avant de mettre à jour

Installez cette version sur le serveur Sagax, puis mettez à jour l'app de bureau et l'app iOS. Les routines, leurs horaires et les fils sont conservés. Rien à configurer.

## English
<!-- date: 2026-11-05 -->

This release fixes roles in the chat and adds chat width, Claude artifacts and sharing a bot's library. It covers the desktop app, the server, iPhone and iPad.

### Roles

* The message box no longer has an “Act as” role picker. A routine's “On behalf of” field shows only for a routine that runs a Pulsatrix Flow recipe. Issue #2032.
* The chat no longer shows any role, on desktop, web and iOS: no role pill on tool steps, no “Acts as” card, no role change notice. The bot panel's Roles tab stays to see the roles used and the missing permissions. Issue #2033.
* The engine usage limit notice has a Close button and stays closed. Issue #2033.

### Chat

* Chat width: Settings > Conversation offers Reading (narrow column), Wide or Full width, for conversations, rooms and coding work. Issue #2004.
* Claude artifacts: when a Claude bot publishes a claude.ai page with your own Claude account, a card shows it in the chat, with its comments, on desktop and iOS. A consent card appears before a publish when the engine's account is not yours. Issue #2018.
* A Codex step whose MCP call fails shows the server's real message instead of “returned no error message”. Issue #1988.
* The model menu opened on its own stays inside the window, and the guided tour skips the Computer step when there is nothing to show. Issues #1979 and #2000.

### Library and Capabilities

* A shared bot also shares its Links, Media and Files with the people in the share, main conversation included. Confidential threads stay out and export stays with the owner.
* On the Perspicax console, a bot's Capabilities are its owner's, not those of the person looking. Issue #2029.

### Routines

* A routine can choose its reasoning level beside its model, without changing the chat. Issue #1999.
* “Needs its computer” can also be set through the bot's tools, and an open routine proposal card shows in pending approvals. Issue #1996.
* When the main engine refuses a run, the check notes the ready backup engine, and the organization's Flow skills follow onto the backup engine.

### Cost and speed

* Claude loads fewer tools up front: rare tools wait behind tool search, which makes every call lighter.
* Switching threads cancels MCP warm-ups still waiting. Issue #1975.
* Codex keeps its app-server process from one turn to the next in a thread, instead of starting a new one for every message. Issue #1969.

### Other fixes

* An OpenAI-compatible server address pasted with /chat/completions keeps the right base address instead of ending in a 404. Issue #2022.
* The bot no longer takes an npm package spec for an email address. Issue #2028.
* Claude Code 2.1.318 is the pinned version.
* Internal code uses one shared helper per need (file sizes, canonical JSON, approval description). Issue #1382.

## Before updating

Install this version on the Sagax server, then update the desktop app and the iOS app. Routines, their schedules and threads are preserved. Nothing to configure.
