# Sagax 0.8.52

Cette version commence la refonte des Réglages (niveaux 0 à 2) et refait le profil et le panneau du bot façon Grok Bot, ainsi que la fenêtre Plugins. Elle ajoute les notifications natives, la puce de modèle dans la barre du chat et les jobs de codage en carte. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

### Réglages

* Fondation L0 de la refonte : navigation et pages de base alignées sur Grok Bot et Cursor. Issue #2087.
* L1 : pages Modèle, Usage, Voix et Fournisseurs. Issue #2080.
* L2 : Notifications, Sécurité et Coffre regroupés ; Compte réduit à l'identité et à Langue et région. Issue #2080.

### Profil et panneau du bot

* La page profil du bot remplace la modale Modifier le bot : bannière, mascotte, onglets Général, Connaissances et Réglages. Issues #2126 et #2136.
* Le panneau du bot suit Grok Bot : engrenage et Fermer, onglets Activity et Library, routines à venir, ordinateur du bot et Voice chat (voix, vitesse, langue du bot). Issue #2125.
* Modifier le bot est plus clair : outils par groupe, dossier par défaut. Issue #2101.
* L'onglet Rôles du panneau disparaît ; une permission manquante paraît dans Détails > Permissions. Issue #2085.
* Sur iPhone et iPad : mêmes vues bot (Activity, panneau gear+X, page profil) et deep links Activity. Issue #2127.

### Plugins

* La fenêtre Plugins reprend Connect Apps de Grok Bot : recherche, modèles de bot, Recommandés, Manage plugins and skills, pages plugin, skill et connecteur. Issue #2104.
* Les écarts restants avec Connect Apps sont comblés. Issue #2104.

### Conversation

* Puce de modèle et sélecteur façon Cursor dans la barre du chat : tu changes le modèle du bot au complet (Auto, Favoris, fournisseurs). Issue #2106.
* Auto reste mémorisé ; le compte suit le plugin MCP ; une seule zone de défilement. Issue #2106.
* En-tête du chat, bannière et largeurs alignés sur Grok Bot. Issue #2141.
* Le bouton Ordinateur quitte l'en-tête du chat. Issue #2094.
* La question d'une tâche parallèle vit dans son propre chat, jamais figée au-dessus du compositeur. Issue #2082.
* Une exécution de routine se lit comme un message du bot, avec Stop sur la carte. Issue #2145.

### Coding

* Le chat de code lit comme le terminal Claude Code ; la section Coding du panneau liste les agents en rangées. Issue #2099.
* Une job de codage lancée depuis le chat reste dans le chat comme une carte (en cours avec Stop, puis terminée avec branche, résultat court et lien PR). Dans Coding, une job terminée reste visible 24 h ou jusqu'à Ignorer. Issue #2148.

### Personnes, équipes et groupes

* Panneau personne : plus d'onglet Connexions, En commun caché s'il est vide, nouvel onglet Bibliothèque. Issue #2117.
* Tu exportes ta propre équipe ; seuls les bots du propriétaire du pack partent avec. Issue #2045.
* Carte d'équipe et barre latérale suivent les noms affichés. Issue #2045.
* Renommer une équipe ne détache plus ses bots : l'appartenance est reprise automatiquement au démarrage du serveur. Issue #2045.
* Dans un groupe, seul le créateur voit Supprimer ; un invité voit Quitter seulement. Issue #2119.

### Courriel et approbations

* Sur /me, la boîte du propriétaire ; la boîte d'une autre personne suit le niveau d'approbation. Issue #1943.
* Toujours permettre (Always allow) passe sur les cartes d'approbation, selon tes réglages. Issues #2100 et #2105.

### Notifications

* Notifications natives : Centre de notifications sur macOS et Windows, regroupement par chat et interrupteurs par type. Issue #2120.

### iPad

* Parité du rail des Réglages L0, horodatage de groupe, Forme et Couleur, puis une cinquième ronde d'alignement avec le bureau. Issue #1939.

### Performance et fiabilité

* Chemin envoi vers premier jeton allégé ; onboarding et Réglages hors du chemin critique. Issue #1971.
* Appels réseau bornés et échecs en arrière-plan journalisés. Issue #2097.
* L'hydratation tolère un instantané sans bots : la galerie ne plante plus. Issue #2116.
* Moins de mémoire et plus de vitesse dans les moteurs, repris d'OpenMausBot.

### Artefacts et compétences

* Consigne de republication quand l'artefact appartient à un autre compte. Issue #2018.
* Nouvelles compétences et routines reprises d'OpenMausBot. Issue #2115.

## Avant de mettre à jour

Installe cette version sur le serveur Sagax, puis mets à jour l'app de bureau et l'app iOS. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés. Certaines pages de Réglages changent de place.

## English

This release starts the Settings redesign (levels 0 to 2) and redoes the bot profile and bot panel in the Grok Bot style, along with the Plugins window. It adds native notifications, the model chip in the chat bar and coding jobs as cards. It covers the desktop app, the server, iPhone and iPad.

### Settings

* L0 foundation of the redesign: navigation and base pages aligned with Grok Bot and Cursor. Issue #2087.
* L1: Model, Usage, Voice and Providers pages. Issue #2080.
* L2: Notifications, Security and Vault grouped; Account reduced to identity and Language and region. Issue #2080.

### Bot profile and panel

* The bot profile page replaces the Edit bot modal: banner, mascot, General, Knowledge and Settings tabs. Issues #2126 and #2136.
* The bot panel follows Grok Bot: gear and Close, Activity and Library tabs, upcoming routines, the bot's computer and Voice chat (voice, speed, language for that bot). Issue #2125.
* Edit bot is clearer: tools by group, default folder. Issue #2101.
* The Roles tab leaves the panel; a missing permission shows in Details > Permissions. Issue #2085.
* On iPhone and iPad: the same bot views (Activity, gear+X panel, profile page) and Activity deep links. Issue #2127.

### Plugins

* The Plugins window matches Grok Bot Connect Apps: search, bot templates, Recommended, Manage plugins and skills, plugin, skill and connector pages. Issue #2104.
* Remaining gaps with Connect Apps are closed. Issue #2104.

### Conversation

* Model chip and Cursor-style picker in the chat bar: you change the bot's model as a whole (Auto, Favorites, providers). Issue #2106.
* Auto stays remembered; the account follows the MCP plugin; one scrolling zone. Issue #2106.
* Chat header, banner and widths aligned with Grok Bot. Issue #2141.
* The Computer button leaves the chat header. Issue #2094.
* A parallel task's question lives in its own chat, never stuck above the composer. Issue #2082.
* A routine run reads as a bot message, with Stop on the card. Issue #2145.

### Coding

* The coding chat reads like the Claude Code terminal; the bot panel's Coding section lists agents in rows. Issue #2099.
* A coding job started from chat stays in the chat as a card (running with Stop, then done with branch, short result and PR link). In Coding, a finished job stays visible for 24 h or until Dismiss. Issue #2148.

### People, teams and groups

* Person panel: no Connections tab, In common hidden when empty, new Library tab. Issue #2117.
* You export your own team; only the pack owner's bots go with it. Issue #2045.
* Team card and sidebar follow display names. Issue #2045.
* Renaming a team no longer detaches its bots: membership is migrated automatically when the server starts. Issue #2045.
* In a group, only the creator sees Delete; a guest sees Leave only. Issue #2119.

### Mail and approvals

* On /me, the owner's mailbox; another person's mailbox follows the approval level. Issue #1943.
* Always allow lands on approval cards, according to your settings. Issues #2100 and #2105.

### Notifications

* Native notifications: Notification Center on macOS and Windows, grouping by chat and per-type toggles. Issue #2120.

### iPad

* Settings L0 rail parity, group timestamps, Shape and Color, then a fifth round of alignment with the desktop. Issue #1939.

### Performance and reliability

* Send-to-first-token path lightened; onboarding and Settings off the critical path. Issue #1971.
* Bounded network calls and background failures logged. Issue #2097.
* Hydration tolerates a snapshot with no bots: the gallery no longer crashes. Issue #2116.
* Lower memory use and more speed in the engines, brought over from OpenMausBot.

### Artifacts and skills

* Republish guidance when the artifact belongs to another account. Issue #2018.
* New skills and routines brought over from OpenMausBot. Issue #2115.

## Before updating

Install this version on the Sagax server, then update the desktop app and the iOS app. Your bots, models, teams, plugins and personal settings are kept. Some Settings pages move.
