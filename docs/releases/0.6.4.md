Sagax 0.6.4 fiabilise l'API membre et laisse le bot principal appliquer directement les changements de vos bots quand vous le demandez.

## Bot principal

* **Changements de bots appliqués tout de suite** : quand vous le demandez clairement à votre bot principal, il change sans carte le modèle, l'instance, l'effort, la persona, le profil, les routines, les équipes gérées, et il archive ou supprime un bot. Plusieurs bots dans un seul ordre. Sans demande de votre part, une proposition reste une carte.
* **Archivage de bot** : nouvel outil `archive_bot` pour masquer un bot sans le supprimer.
* **Tous vos bots** : le bot principal vise tous les bots de sa personne, sans refus lié à l'équipe gérée. Une proposition en attente ne bloque plus les suivantes.

## Serveur d'organisation

* **API membre** : toute réponse de l'API membre porte maintenant l'en-tête `x-sagax-member-api: 1`, même en cas d'erreur, et l'exception est écrite dans le journal. Fini le faux message « ce serveur n'offre pas encore l'API membre ».
* **Connaissance de Sagax** : le bot connaît Perspicax 1.8.42.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.6.4-arm64.dmg` ou `Sagax-0.6.4-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.6.4-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.6.4-win-x64.zip` et `Sagax-0.6.4-win-arm64.zip`.

## English

Sagax 0.6.4 makes the member API more reliable and lets the primary bot apply changes to your bots directly when you ask.

* **Bot changes applied at once**: when you clearly ask your primary bot, it changes a bot's model, instance, effort, persona, profile, routines or managed teams without a card, and archives or deletes a bot. Several bots in one order. Without your request, a proposal stays a card.
* **Bot archiving**: new `archive_bot` tool to hide a bot without deleting it.
* **All your bots**: the primary bot targets every bot of its person, with no refusal tied to the managed team. A pending proposal no longer blocks the next ones.
* **Member API**: every member API response now carries the `x-sagax-member-api: 1` header, errors included, and the exception is written to the log. No more false "this server does not offer the member API yet" message.
* **Self-knowledge**: the bot knows Perspicax 1.8.42.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
