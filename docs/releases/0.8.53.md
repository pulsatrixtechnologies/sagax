# Sagax 0.8.53

Cette version continue la refonte des Réglages (Providers et Models plus simples, section Application retirée), allège encore le chat et poursuit l'alignement de l'iPad et de l'iPhone avec le bureau. Les rapports de routine se lisent comme un message du bot et les diffs du chat de code sont repliés par défaut. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

### Réglages

* Providers et Models plus simples : un état et une action par rangée, comptes séparés des fournisseurs, rien n'est retiré (le détail reste derrière un clic). Issue #2080.
* La section Application disparaît des Réglages, Import est caché au complet et À propos quitte les Réglages. Issue #2090.

### Conversation

* Un rapport de routine terminé se lit comme un message normal du bot, avec une discrète ligne d'origine ; les cartes restent pour les états en cours. Bureau et iOS. Issue #2081.

### Routines

* Un clic sur une routine en cours ouvre sa fiche, comme pour les autres routines ; l'exécution en cours reste dans la liste Runs. Issue #2188.

### Coding

* Dans le chat de code, les diffs sont repliés par défaut et l'en-tête est plus compact, comme dans Claude Code. Issue #2108.

### iPhone et iPad

* Sur iPhone et iPad, le panneau d'une personne ouvre Profil, Bibliothèque et Réussites comme sur le bureau ; En commun se cache s'il est vide. Issue #1939.
* Sur iPad, l'en-tête du chat montre la pilule de nom, l'audience et l'engrenage, et le panneau du bot a la même largeur que sur le bureau. Issue #1939.

### Performance et fiabilité

* L'envoi d'un message n'attend plus la sauvegarde de la carte Connectors : le chat part plus vite. Issue #1971.
* Les règles, la mémoire, l'index des docs et les skills se reconstruisent seulement quand le workspace change : le premier jeton arrive plus vite. Issue #1971.
* Le code interne des moteurs et des fonctions les plus longues est découpé en morceaux plus petits, sans changement visible. Issue #1383.

## Avant de mettre à jour

Installe cette version sur le serveur Sagax, puis mets à jour l'app de bureau et l'app iOS. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés. Certaines pages de Réglages changent de place.

## English

This release continues the Settings redesign (simpler Providers and Models, Application section removed), lightens the chat further and keeps aligning iPad and iPhone with the desktop. Routine reports read like a bot message and diffs in the coding chat are collapsed by default. It covers the desktop app, the server, iPhone and iPad.

### Settings

* Simpler Providers and Models: one state and one action per row, accounts separated from providers, nothing removed (detail stays one click away). Issue #2080.
* The Application section leaves Settings, Import is fully hidden and About moves out of Settings. Issue #2090.

### Conversation

* A finished routine report reads as a normal bot message with a discreet origin line; cards remain for in-progress states. Desktop and iOS. Issue #2081.

### Routines

* Clicking a running routine opens its page, like any other routine; the current run stays in the Runs list. Issue #2188.

### Coding

* In the coding chat, diffs are collapsed by default and the header is more compact, like Claude Code. Issue #2108.

### iPhone and iPad

* On iPhone and iPad, a person's panel opens Profile, Library and Achievements like the desktop; In common hides when empty. Issue #1939.
* On iPad, the chat header shows the name pill, audience and gear, and the bot panel matches the desktop width. Issue #1939.

### Performance and reliability

* Sending a message no longer waits for the Connectors card save: the chat leaves faster. Issue #1971.
* Rules, memory, the docs index and skills rebuild only when the workspace changes: the first token arrives faster. Issue #1971.
* The longest engine and internal functions are split into smaller pieces, with no visible change. Issue #1383.

## Before updating

Install this version on the Sagax server, then update the desktop app and the iOS app. Your bots, models, teams, plugins and personal settings are kept. Some Settings pages move.
