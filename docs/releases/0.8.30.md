# Sagax 0.8.30

Correctif serveur : les appels vocaux avec un bot se connectent de nouveau.

### Appels vocaux

* Les appels vocaux se connectent de nouveau, et si un appel coupe, le message dit pourquoi (session refusée, clé de voix refusée, erreur du serveur ou réseau) au lieu de « L'appel a coupé ».

## Avant de mettre à jour

Rien à préparer. Ce correctif touche seulement le serveur : l'app de bureau et l'app iOS restent sur 0.8.29. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image.

## English
<!-- date: 2026-11-02 -->
Server fix: voice calls with a bot connect again.

### Voice calls

* Voice calls connect again, and when a call drops, the message says why (sign-in refused, voice key refused, server error or network) instead of "The call dropped".

## Before you update

Nothing to prepare. This fix touches only the server: the desktop and iOS apps stay on 0.8.29. If you self-host Sagax, keep a copy of your data (`docs/self-hosting.md`) before replacing the image.
