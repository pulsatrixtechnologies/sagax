# Sagax 0.8.41

Correctif serveur : avec le moteur Codex, les outils MCP fonctionnent de nouveau dans les routines et les tours lancés par MCP.

### Moteur Codex

* En accès complet, un appel d'outil MCP n'est plus refusé par Codex avec « MCP tool call requires approval, but approval policy is never ». La demande passe par la décision d'approbation de Sagax, comme pour les autres moteurs, et la carte arrive à la personne quand une approbation est requise. Issue #1977.

## Avant de mettre à jour

Rien à préparer. Ce correctif touche seulement le serveur : l'app de bureau et l'app iOS restent sur 0.8.40. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image.

Server fix: with the Codex engine, MCP tools work again in routines and in turns started over MCP.

### Codex engine

* With full access, an MCP tool call is no longer refused by Codex with "MCP tool call requires approval, but approval policy is never". The request goes through Sagax's approval decision, as with the other engines, and the card reaches the person when an approval is required. Issue #1977.

## Before you update

Nothing to prepare. This fix touches only the server: the desktop and iOS apps stay on 0.8.40. If you self-host Sagax, keep a copy of your data (`docs/self-hosting.md`) before replacing the image.
