Sagax 0.4.0 est la première version complète (non préliminaire) de Sagax, la lignée Pulsatrix basée sur Sagax 0.1.92. Ce n'est pas une version officielle d'Sagax.

## Nouveautés

* **Sagax, Pulsatrix Technologies Inc.** : le nom Sagax disparaît de l'application (compatibilité gardée : `~/.sagax`, liens sous l'ancien schéma d'URL). Les changements de Sagax sont publiés sous licence PolyForm Noncommercial 1.0.0 ; le code d'origine reste sous Apache 2.0. (Mention remplacée : Sagax est maintenant entièrement sous licence Apache 2.0, versions antérieures comprises.)
* **Aucun appel vers l'extérieur** : pas de télémétrie, les mises à jour viennent uniquement de nos versions GitHub, les services Sagax sont bloqués.
* **Mode organisation Perspicax**
  * Écran de lancement : **Pas de serveur** (Sagax solo) ou **Serveur**, connexion dans le navigateur du système (clés d'accès, gestionnaires de mots de passe).
  * Mode serveur exclusif, même interface que Sagax solo, préférences par personne.
  * Fils privés avec un bot partagé, discussions de groupe, messages directs entre personnes, mémoire de groupe partagée par les bots du groupe.
  * La personne qui parle paie ; les routines paient au nom de leur propriétaire ; délégation des routines gérée depuis la page d'accès Perspicax de la personne.
  * Connecteurs claude.ai du compte de la personne qui parle ; commandes slash des moteurs par bot et par personne.
  * Bot principal (étoile orange) à la place du chef de cabinet.
  * Nom, courriel et avatar gérés par Perspicax ; réglages d'organisation nettoyés, actions forcées pour l'admin.
* **Ordinateurs des bots**
  * Un bac à sable isolé par personne sur les serveurs d'organisation, avec bureau, contrôle de l'ordinateur, vue en direct et consommation dans l'onglet Ordinateur.
  * Pont de bureau : les bots travaillent sur l'ordinateur de la personne qui parle ; VM locale créée sur le PC, sortie SOCKS et PAC.
  * Mode Accès complet (contournement des permissions) avec politique d'organisation.
  * Écran Ordinateur : bureau en direct avec **Prendre le contrôle** ; « Travaille sur » choisit l'environnement du serveur (Cloud) en mode organisation.
* **Voix** : un vrai appel téléphonique (duplex intégral, interruption, diffusion en continu, détection de voix locale, « Seulement ma voix ») ; mode voix sur serveur avec xAI.
* **Mascotte et apparence** : la vraie chouette Sagax en 2D et en 3D, treize formes originales, Trombi, habillages premium avec onglets de rareté et habillages de chouette, option pour masquer le logo de la barre latérale.
* **Discussion avec la mascotte** plus fluide, aux couleurs du thème de l'application.
* **Windows arm64** : installateur unique x64 et arm64, et version portable arm64.
* **README** refait et **correctifs de tests** (suite verte, exécution par lots).
* **Interface** : panneau du bot repensé (Détails, Bibliothèque, Ordinateur, Plus), liste des bots d'organisation repensée, choix du modèle dans une fenêtre dédiée, réglages Courriel (SMTP, SendGrid, Twilio).
* **Sagax 0.1.92** fusionné en amont (citations de texte sélectionné, barre latérale redimensionnable, connexion au forfait ChatGPT, correctifs Windows et MCP).

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.4.0-arm64.dmg` ou `Sagax-0.4.0-x64.dmg` et glissez Sagax dans Applications. L'application est signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.4.0-setup.exe`, un seul installateur pour les deux. Il n'est pas signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.4.0-win-x64.zip` et `Sagax-0.4.0-win-arm64.zip`.

Les versions jusqu'à 0.3.0 s'appelaient `PulsaBot-...` ; la mise à jour intégrée passe à Sagax sans action.

## English

Sagax 0.4.0 is the first full (non pre-release) Sagax release, the Pulsatrix line based on OpenMausBot 0.1.92. It is not an official OpenMausBot release.

* **Sagax by Pulsatrix Technologies Inc.**: the Sagax name is gone from the app (compatibility kept). Sagax changes are licensed under PolyForm Noncommercial 1.0.0; the original code stays Apache 2.0. (Superseded: Sagax is now entirely under the Apache License 2.0, earlier releases included.)
* **No phone-home**: no telemetry, updates only from our GitHub releases, Sagax services blocked.
* **Perspicax organization mode**: No server or Server at launch, system browser sign-in, exclusive server mode with the solo UI, private threads, group chats, direct messages, shared group memory, the speaker pays, routines pay as their owner with self-service delegation, the speaker's own Claude connectors, per-bot and per-speaker slash commands, Primary Bot.
* **Bot computers**: one isolated sandbox per person with desktop, computer use and live view; Computer screen with Take control; desktop bridge to the speaker's own computer (Local VM, SOCKS and PAC egress); Full access mode with an organization policy.
* **Voice**: a real phone call (full duplex, barge-in, streaming, on-device VAD, Only my voice); voice in server mode with xAI.
* **Mascot and appearance**: the Sagax owl in 2D and 3D, thirteen original shapes, Trombi, premium skins with rarity tabs and owl skins, hide the sidebar logo; smoother mascot chat in the app theme.
* **Windows arm64**: one installer for x64 and arm64, plus an arm64 portable zip.
* **README** overhaul and **test fixes** (green suite, sharded runner).
* **UI**: redesigned bot panel and organization bots list, model picker modal, Email settings.
* **Upstream OpenMausBot 0.1.92** merged.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
