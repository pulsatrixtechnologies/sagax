# Sagax 0.8.58

Tes bots peuvent maintenant utiliser les apps Apple de ton Mac (Messages, Mail, Calendrier, Contacts, Rappels, Notes). Le panneau Ordinateurs t'offre la Prise en main à distance sans surveillance et s'ouvre à tous les membres. Chaque compte de fournisseur ajouté se connecte enfin de son côté. Le chat garde la même pastille partout et la ligne de travail reste au-dessus de la zone de saisie. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

## Mac

* Tes bots peuvent lire et envoyer avec les apps Apple : Messages, Mail, Calendrier, Contacts, Rappels et Notes, en mode solo comme sur un serveur. Chaque app a sa page de réglage (permissions, ouvrir les Réglages macOS, test, On/Off). PR #2371.
* La section Ce Mac n'apparaît que sur macOS, et la page de réglage de Messages n'est plus jamais vide : tu vois le chargement, puis une erreur claire avec Réessayer au besoin. PR #2371.

## Ordinateurs

* La carte Connect Boat fait place à la configuration de Prise en main à distance sans surveillance : portée, code et commande d'installation, lien d'inscription. Les ordinateurs inscrits s'affichent avec leur état en ligne et tu peux les glisser sur une équipe ; ses bots en héritent. PR #2365.
* Le panneau Ordinateurs et l'entrée Unattended computer sont ouverts à tout membre, sans passer par un administrateur. PR #2367.

## Chat

* La même pastille et les mêmes fondus en haut et en bas dans toutes les vues de chat : chat régulier, nouveau sujet, groupe, bot à bot, vue partagée, Coding et routine. Effacer le chat passe dans le menu « ... ». PR #2375.
* Le panneau du bot gagne un onglet Code quand une session de code vise ce bot. PR #2375.
* La ligne de travail (points ou mascotte, phrase, minuterie) reste toujours juste au-dessus de la zone de saisie au lieu de défiler avec le chat ; l'attente « termine une autre conversation » l'utilise aussi. PR #2378.

## Modèles et fournisseurs

* Les réglages d'équipe et le lancement d'une session de code utilisent le même menu de modèle que la barre du chat. PR #2363.
* Sur un serveur, chaque compte de fournisseur ajouté se connecte dans son propre dossier : un deuxième compte n'écrase plus le premier et te déconnecter d'un compte ne déconnecte plus les autres. PR #2377.

## Plugins

* Sous Moi, « + Ajouter » offre les mêmes trois choix que sous Organisation : ajouter un serveur MCP, coller une config, nouveau skill. Tes serveurs MCP personnels s'affichent dans Installés avec toutes leurs actions. PR #2374.

## Outils

* Les pages Automations, Mémoire et Succès prennent le même en-tête que la Carte d'équipe, et chaque niveau du fil d'Ariane est cliquable. PR #2369.

## Apparence

* Neuf icônes de personnages s'ajoutent au choix d'icône de l'app : Block, Droplet, Teardrop, Spiky, Triangle, Sprout, Oblong, Ghost et Blob. PR #2380.

## Fiabilité

* Le chat ne se redessine plus à chaque étape d'une routine en cours. PR #2383.

## English

Your bots can now use your Mac's Apple apps (Messages, Mail, Calendar, Contacts, Reminders, Notes). The Computers panel offers Unattended Remote Control and opens to every member. Each added provider account finally signs in on its own. The chat keeps the same pill everywhere and the working line stays above the composer. It covers the desktop app, the server, iPhone and iPad.

### Mac

* Your bots can read and send with the Apple apps: Messages, Mail, Calendar, Contacts, Reminders and Notes, in solo mode and on a server. Each app has its own setup page (permissions, open macOS Settings, test, On/Off). PR #2371.
* The This Mac section shows on macOS only, and the Messages setup page is never blank: you see it loading, then a clear error with Retry when needed. PR #2371.

### Computers

* The Connect Boat card gives way to the Unattended Remote Control setup: scope, install code and command, enroll link. Enrolled computers show with their online state and you can drag them onto a team; its bots inherit them. PR #2365.
* The Computers panel and the Unattended computer entry are open to every member, with no administrator needed. PR #2367.

### Chat

* The same pill and the same top and bottom fades in every chat view: regular chat, new topic, group, bot to bot, split view, Coding and routine. Clear chat moves into the "..." menu. PR #2375.
* The bot panel gains a Code tab when a coding session targets that bot. PR #2375.
* The working line (dots or mascot, phrase, timer) always stays just above the composer instead of scrolling with the chat; the "finishing another conversation" wait uses it too. PR #2378.

### Models and providers

* Team settings and the coding session launch use the same model menu as the chat bar. PR #2363.
* On a server, each added provider account signs in on its own folder: a second account no longer overwrites the first, and signing out of one account no longer signs out the others. PR #2377.

### Plugins

* Under Me, "+ Add" offers the same three choices as under Organization: add an MCP server, paste a config, new skill. Your personal MCP servers show in Installed with all their actions. PR #2374.

### Tools

* The Automations, Memory and Achievements pages get the same header as the Team map, and every breadcrumb level is clickable. PR #2369.

### Appearance

* Nine character icons join the app icon picker: Block, Droplet, Teardrop, Spiky, Triangle, Sprout, Oblong, Ghost and Blob. PR #2380.

### Reliability

* The chat no longer redraws on every step of a running routine. PR #2383.
