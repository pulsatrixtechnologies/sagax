Sagax 0.8.124 met un seul contrôle « Exécuté avec » partout où tu choisis un modèle, et laisse un bot changer un passage choisi d'une page sur place.

### Ce que tu remarques d'abord

* **Un seul contrôle « Exécuté avec » (#4401)** : la page d'un fournisseur, le menu des modèles, les modèles des bots et la section Modèle d'un bot montrent le même contrôle.
  * Sur la page d'un fournisseur, ton choix devient ton réglage par défaut.
  * Dans le menu des modèles, la ligne « Exécuté avec » règle le choix du bot au lieu de choisir une autre rangée de moteur.
  * Dans les modèles des bots, une colonne « Exécuté avec » apparaît quand un bot a un choix à faire.
  * Le contrôle est caché quand une seule valeur est possible, et il liste exactement ce que ton choix va lancer.
  * pi et OpenCode lancent un modèle de fournisseur quand ils le listent avec leur propre accès.
* **Un bot change un passage choisi d'une page sur place (#4409)** : pour une page en Markdown ou une présentation, le bot remplace seulement les mots visés, et la nouvelle version proposée s'affiche directement dans la page.
  * Si les mots ne sont pas trouvés, ou le sont plus d'une fois, le bot reçoit une erreur et renvoie la page entière.
  * Un changement dans une page en Markdown garde le type de la version qu'il modifie.

### Ce qui reste pour une version suivante

* Les applications iPhone et iPad dessinent encore d'anciennes cartes de passage de routine dans une conversation jusqu'à la sortie de leur propre filtre.

## Avant de mettre à jour

Si tu héberges Sagax toi-même, garde une copie de tes données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.124 puts one Runs with control everywhere you pick a model, and lets a bot change a selected passage of a page in place.

### What you notice first

* **One Runs with control (#4401)**: a provider's page, the model menu, Bot models and a bot's Model section show the same control.
  * On a provider's page, your pick becomes your default.
  * In the model menu, the Runs with line sets the bot's choice instead of picking another engine row.
  * In Bot models, a Runs with column appears when a bot has a choice to make.
  * The control is hidden when only one value is possible, and it lists exactly what your pick will run.
  * pi and OpenCode run a provider's model when they list it with their own way in.
* **A bot changes a selected passage of a page in place (#4409)**: for a Markdown page or a presentation, the bot replaces only the words aimed at, and the new proposed version is drawn right in the page.
  * If the words are not found, or are found more than once, the bot gets an error and sends the whole page.
  * A change in a Markdown page keeps the kind of the version it changes.

### What stays for a later version

* The iPhone and iPad apps still draw old routine run cards in a conversation until their own filter ships.

## Before you update

If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
