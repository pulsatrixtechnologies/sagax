# Sagax 0.8.45

La vérification des routines Flow reconnaît maintenant le nom explicite de la recette dans le prompt, y compris dans une consigne « Passe Pulsatrix Flow » suivie d'un nom entre backticks. Une consigne comme « suis la routine Flow jusqu'à la fin » ne devient plus un faux nom de recette.

* Une recette nommée vérifie son initialisation en shadow. Le premier plan est vérifié seulement si le prompt fournit explicitement cette commande et ses arguments; le modèle peut découvrir les unités pendant le vrai travail.
* Chaque vérification utilise un client MCP distinct, tout en gardant l'identité de la personne. Ses appels de plan et de libération précisent la recette et le run exacts pour éviter les collisions entre vérifications parallèles et avec le travail en cours.
* Sans recette explicite, la vérification confirme la connexion et le catalogue, puis laisse le modèle choisir la recette.

## English
<!-- date: 2026-11-04 -->

Flow readiness now recognizes the explicit recipe name in a prompt, including a backtick-quoted name after “Passe Pulsatrix Flow”. Instructions such as “follow the Flow routine until it finishes” no longer become a false recipe name.

* A named recipe checks its shadow initialization. Readiness checks a first plan only when the prompt explicitly supplies that command and its arguments; the model can discover units during the actual work.
* Every probe uses a distinct MCP client while retaining the person's identity. Plan and release calls specify the exact recipe and run to avoid collisions between parallel probes and with work already running.
* Without an explicit recipe, readiness checks the connection and catalogue, then lets the model choose the recipe.
