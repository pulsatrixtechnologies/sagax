# Sagax 0.8.39

Correctif serveur : un bot relié à Perspicax sait où lire les skills Pulsatrix Flow quand l'installation de l'organisation est retenue.

### Pulsatrix Flow

* Quand Perspicax retient l'installation de Pulsatrix Flow pour l'organisation, un bot relié à un profil Perspicax ne cherche plus en vain les skills Flow dans son catalogue ou son espace de travail. Son index de skills dit pourquoi ils ne sont pas chargés et comment les lire dans le pack Flow actif, après l'ouverture de la passe, par une lecture `doc` de `flow_run`.
* Une routine qui demande de charger un skill Flow continue sa passe de cette façon au lieu de s'arrêter parce qu'une copie locale manque.

## Avant de mettre à jour

Rien à préparer. Ce correctif touche seulement le serveur : l'app de bureau et l'app iOS restent sur 0.8.36. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image.

## English
<!-- date: 2026-11-04 -->
Server fix: a bot linked to Perspicax knows where to read the Pulsatrix Flow skills when the organization install is held back.

### Pulsatrix Flow

* When Perspicax holds back the organization's Pulsatrix Flow install, a bot linked to a Perspicax profile no longer searches its catalog or workspace for the Flow skills in vain. Its skills index says why they are not loaded and how to read them from the active Flow pack, once the pass is open, with a `flow_run` `doc` read.
* A routine that asks to load a Flow skill goes on with its pass this way instead of stopping because a local copy is missing.

## Before you update

Nothing to prepare. This fix touches only the server: the desktop and iOS apps stay on 0.8.36. If you self-host Sagax, keep a copy of your data (`docs/self-hosting.md`) before replacing the image.
