Sagax 0.8.120 range la page d'une routine en trois onglets, pour que ses options ne soient plus un long mur.

### Ce que tu remarques d'abord

* **La page d'une routine en trois onglets (#4369)** : la page de la routine, dans le panneau latéral, n'est plus un seul long panneau avec toutes les options dans un bloc Avancé.
  * **Vue d'ensemble** : l'instruction est repliée (Afficher plus), la section Quand montre chaque déclencheur (l'horaire, un webhook avec Copier sur sa ligne, l'étiquette de courriel, la veille), puis la prochaine exécution et la dernière exécution sur une seule ligne. Un webhook manquant montre son avis et le bouton Créer juste sous Quand.
  * **Exécutions** : tout l'historique, une ligne par exécution, groupé par jour, avec Effacer les journaux d'exécution en haut ; le nombre d'exécutions est sur l'onglet.
  * **Réglages** : toutes les options qui existaient, sous de courts titres (Qui l'exécute, Conditions, Limites, Horaire, Résultats, Autres). Une option qui ne peut pas s'appliquer reste cachée, et « Au nom de » se règle une seule fois, ici.

### Ce qui reste pour une version suivante

* Les applications iPhone et iPad dessinent encore d'anciennes cartes de passage de routine dans une conversation jusqu'à la sortie de leur propre filtre.

## Avant de mettre à jour

Si tu héberges Sagax toi-même, garde une copie de tes données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.120 puts a routine's page in three tabs, so its options are no longer one long wall.

### What you notice first

* **A routine's page in three tabs (#4369)**: the routine page in the side panel is no longer one long pane with every option in an Advanced fold.
  * **Overview**: the instruction is folded (Show more), When shows every trigger (the schedule, a webhook with Copy on its line, the mail tag, the watch), then the next run and the last run on one line. A missing webhook shows its notice and the Create button right under When.
  * **Runs**: the whole history, one line per run, grouped by day, with Clear run logs at the top; the run count is on the tab.
  * **Settings**: every option that existed, under short headings (Who runs it, Conditions, Limits, Timing, Results, More). An option that cannot apply stays hidden, and "On behalf of" is set once, here.

### What stays for a later version

* The iPhone and iPad apps still draw old routine run cards in a conversation until their own filter ships.

## Before you update

If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
