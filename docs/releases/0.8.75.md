Sagax 0.8.75 rend les routines plus fiables et plus parlantes : un run bloqué dit pourquoi dans le chat du bot, les runs pris au démarrage ne sont plus bloqués à tort, et pi n'offre que les modèles que vous pouvez vraiment payer.

### Routines

* **Run bloqué visible** : un run bloqué ou sauté avant de démarrer (déconnecté, moteur encore en démarrage, Perspicax limité ou injoignable) l'explique maintenant en une ligne dans le chat du bot, dans votre langue. La même ligne n'est pas répétée.
* **Démarrage du serveur** : un run rattrapé au démarrage n'est plus bloqué parce que les connexions n'étaient pas encore chargées. Sagax réessaie quelques fois pendant trois minutes, puis le saute avec une raison claire. Une vraie déconnexion reste signalée tout de suite.
* **Boucles** : les appels d'outils des bots Grok sont comptés avec leurs vrais arguments, donc une routine qui fait plusieurs appels différents n'est plus coupée comme une boucle. L'avis d'arrêt d'une boucle est traduit et s'affiche aussi dans le chat du bot.
* **Erreurs d'outils** : les étapes d'un run montrent le texte d'erreur d'un outil qui échoue, et les problèmes d'une routine ne sont plus coupés au milieu d'un mot.
* **Liste des runs** : la section Runs montre les 3 plus récents, puis Afficher plus. Le compteur garde le total.

### Modèles

* **pi** : le sélecteur de modèle et la fiche du bot n'offrent que les modèles des fournisseurs pour lesquels le payeur du tour a une clé (vos clés Perspicax, sinon celles de l'organisation quand la règle le permet). Un modèle sans clé est refusé avec la liste des fournisseurs disponibles, jamais remplacé en silence.

### Outils

* **Résultats volumineux** : un identifiant de résultat envoyé au mauvais lecteur est redirigé vers le bon, et le message d'erreur nomme le bon outil.

## Avant de mettre à jour

Rien à préparer à la main pour 0.8.75. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.75 makes routines more reliable and more talkative: a blocked run says why in the bot's chat, runs caught up at startup are no longer wrongly blocked, and pi only offers models you can actually pay for.

### Routines

* **Blocked run visible**: a run blocked or skipped before it starts (signed out, engine still starting, Perspicax rate limited or unreachable) now explains it in one line in the bot's chat, in your language. The same line is not repeated.
* **Server startup**: a run caught up at startup is no longer blocked because the sign-ins had not loaded yet. Sagax retries a few times over three minutes, then skips it with a clear reason. A real sign-out is still reported at once.
* **Loops**: Grok bots' tool calls are counted with their real arguments, so a routine making several different calls is no longer cut as a loop. The loop stop notice is translated and also shows in the bot's chat.
* **Tool errors**: a run's steps show the error text of a failing tool, and routine problems are no longer cut in the middle of a word.
* **Runs list**: the Runs section shows the 3 most recent, then Show more. The counter keeps the total.

### Models

* **pi**: the model picker and the bot's panel only offer models of providers the turn's payer holds a key for (your Perspicax keys, else the organization's when the rule allows it). A model without a key is refused with the list of available providers, never swapped silently.

### Tools

* **Large results**: a result handle sent to the wrong reader is routed to the right one, and the error message names the right tool.

## Before updating

Nothing to prepare by hand for 0.8.75. If you self-host, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
