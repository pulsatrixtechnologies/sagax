Sagax 0.7.1 embarque tailcat 0.7.0. La session à distance s'ouvre sans installer tailcat dans le PATH du système.

## Tailcat livré avec Sagax

* L'application lance le tailcat qu'elle contient. Elle le trouve aussi dans son dossier de données, puis dans Homebrew ou `/usr/local/bin`.
* L'image du serveur et l'image de l'ordinateur cloud incluent le même binaire Linux. L'ordinateur cloud déjà en cours ne le voit qu'après la publication de sa nouvelle image.
* Une copie dans `/usr/bin` n'est pas nécessaire.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.7.1-arm64.dmg` ou `Sagax-0.7.1-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.7.1-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.7.1-win-x64.zip` et `Sagax-0.7.1-win-arm64.zip`.

## English

Sagax 0.7.1 ships tailcat 0.7.0. A remote session opens without installing tailcat on the system PATH.

* The app runs the tailcat it contains. It also checks its data directory, then Homebrew or `/usr/local/bin`.
* The server image and the cloud computer image include the same Linux binary. A cloud computer that is already running sees it only after that image is published.
* Copying it into `/usr/bin` is not required.
