Sagax 0.7.0 affiche la session Tailcat dans le panneau du bot et dans le chat, pour faire le soutien à distance depuis Sagax.

## Sessions à distance

* **Panneau du bot** : une session connectée apparaît sous Sessions à distance, avec le poste, l'utilisateur, le code et l'heure de fin. Fermer la session demande une confirmation.
* **Prendre le contrôle** : cliquer la session l'ouvre dans l'onglet Ordinateur. L'écran est une capture en lecture seule.
* **Carte dans le chat** : poste, utilisateur, droits, code, numéro de série, modèle, processeur, mémoire et disque. Les pistes envoient une demande de diagnostic.
* **Shell** : une demande de shell ouvre le terminal du chat sur ce poste.
* **Fichiers** : envoyer un fichier (8 Mo) ou en télécharger un, depuis la carte.
* L'adresse du tunnel et la clé restent sur l'ordinateur. Elles ne s'affichent pas.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.7.0-arm64.dmg` ou `Sagax-0.7.0-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.7.0-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.7.0-win-x64.zip` et `Sagax-0.7.0-win-arm64.zip`.

## English

Sagax 0.7.0 shows the connected Tailcat session in the bot panel and in the chat, so remote support happens inside Sagax.

* **Bot panel**: a connected session appears under Remote sessions, with the computer, the user, the code and the end time. Closing asks for a confirmation.
* **Take control**: clicking the session opens it on the Computer tab. The screen is a read-only capture.
* **Chat card**: computer, user, rights, code, serial number, model, processor, memory and disk. The leads send a diagnostic request.
* **Shell**: asking for a shell opens the in-chat terminal on that computer.
* **Files**: send a file (8 MB) or download one from the card.
* The tunnel address and the key stay on this computer. They are not shown.
