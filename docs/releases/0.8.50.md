# Sagax 0.8.50

Cette version refait trois pages de réglages : Réglages > Fournisseurs, Réglages > Modèles et l'onglet Modèle d'un bot. Une seule page pour tout le monde, les choix de l'organisation en lecture seule avec le lien vers Perspicax, et plus rien de caché par le mode Simple ou Avancé global : chaque page a son propre repli Avancé. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

### Fournisseurs

* Une seule liste des fournisseurs : chaque ligne dit qui paie (moi, l'organisation, cet ordinateur), son état, combien de modèles sont actifs et l'action à faire (Entrer la clé, Reconnecter, Démarrer, Gérer). Issue #2050.
* Sur un serveur d'organisation, les fournisseurs et les clés de l'organisation se lisent tels quels, pour tout le monde, administrateurs compris, avec le bouton Gérer dans Perspicax. La vue « Voir comme un membre » disparaît : la page est la même pour tous. Issue #2050.
* Autres services (recherche web, génération d'images) sur la même page ; sous Avancé, vos clés d'agents de codage infonuagiques et vos connecteurs claude.ai. Issue #2050.

### Modèles

* La page montre quel modèle chaque bot utilise : un tableau des bots avec modèle et effort, la sélection en lot (Tous les bots) et Choisir le modèle pour plusieurs bots d'un coup. Issue #2050.
* Nouveau sélecteur de modèle en deux volets : les fournisseurs à gauche, leurs modèles à droite, avec des Favoris par personne (une étoile sur chaque modèle) qui suivent la personne d'un appareil à l'autre. Issue #2050.
* Sur un serveur d'organisation, les modèles par défaut choisis dans Perspicax se lisent ici avec leur lien ; sous Avancé, les modèles actifs par fournisseur, ce qu'Auto choisirait maintenant et le cache de prompt. Issue #2050.

### Modèle d'un bot

* Trois cartes : Modèle (le même sélecteur, l'effort toujours visible, l'ordinateur hôte), En cas d'échec et Avancé. Issue #2050.
* En cas d'échec réunit la relève automatique et les modèles de relève : un interrupteur « Changer de modèle en cas d'échec », puis la liste ordonnée des relèves (ajouter, monter, descendre, retirer, jusqu'à cinq). La première relève de la liste est aussi la relève unique du bot ; le serveur garde les deux réglages. Issue #2050.
* Avancé, replié par défaut : Qui paie les réponses et Garder le cache de prompt chaud, avec les mêmes droits qu'avant. Issue #2050.

## Avant de mettre à jour

Installez cette version sur le serveur Sagax, puis mettez à jour l'app de bureau et l'app iOS. Les fournisseurs, les clés, les modèles des bots, leurs relèves et les réglages personnels sont conservés tels quels ; seule leur présentation change. Les réglages de l'organisation se changent dans Perspicax.

## English
<!-- date: 2026-11-05 -->

This release redesigns three settings pages: Settings > Providers, Settings > Models and a bot's Model tab. One page for everyone, the organization's choices read-only with a link to Perspicax, and nothing hidden by the global Simple or Advanced mode any more: each page has its own Advanced fold. It covers the desktop app, the server, iPhone and iPad.

### Providers

* One list of providers: each row says who pays (me, the organization, this computer), its state, how many models are active and what to do next (Enter key, Reconnect, Start, Manage). Issue #2050.
* On an organization server the organization's providers and keys read as they stand, for everyone, admins included, with a Manage in Perspicax button. The "View as a member" switch is gone: the page is the same for all. Issue #2050.
* Other services (web search, image generation) on the same page; under Advanced, your cloud coding agent keys and your claude.ai connectors. Issue #2050.

### Models

* The page shows which model each bot uses: a table of bots with model and effort, batch selection (All bots) and Set model for several bots at once. Issue #2050.
* New two-pane model selector: providers on the left, their models on the right, with per-person Favorites (a star on every model) that follow the person across devices. Issue #2050.
* On an organization server the defaults chosen in Perspicax read here with their link; under Advanced, the active models per provider, what Auto would choose now and the prompt cache. Issue #2050.

### A bot's Model

* Three cards: Model (the same selector, the effort always shown, the host computer), If it fails and Advanced. Issue #2050.
* If it fails merges automatic recovery and the backup models: a "Switch model if it fails" switch, then the ordered backups (add, move up, move down, remove, up to five). The first backup in the list is also the bot's single backup; the server keeps both settings. Issue #2050.
* Advanced, closed by default: Who pays for replies and Keep prompt cache warm, with the same rights as before. Issue #2050.

## Before updating

Install this version on the Sagax server, then update the desktop app and the iOS app. Providers, keys, bot models, their backups and personal settings are kept as they are; only their presentation changes. Organization settings are changed in Perspicax.
