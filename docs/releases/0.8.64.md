# Sagax 0.8.64

Cette version simplifie l'app pour tout le monde : les options techniques passent dans Developer, la page du bot est refaite, et un bot Feedback partagé envoie un signalement en un clic. Elle ajoute aussi les équipes de codage (import d'un plugin Claude Code, déclencheurs GitHub) et la gestion des permissions du système en une seule action.

## Simplicité

* Toutes les options techniques (MCP, jetons, webhooks, journaux, embeddings, dossier de travail, export zip) vivent maintenant dans Réglages > Developer ; chaque option est à un seul endroit.
* Nouvelle page du bot : des rangées claires qui ouvrent chacune leur sous-page, et des statistiques d'usage par compte, modèle, source et personne.
* Une marque « Partagé » ou « Partiellement partagé » suit le nom d'un bot dans la barre de gauche.

## Feedback

* Nouveau bot Feedback partagé : décris un problème ou une idée, vérifie l'aperçu anonymisé, puis envoie en un clic.
* Accessible depuis le pied de la barre de gauche, le menu Aide (Cmd/Ctrl+Shift+F), `/feedback` dans tout chat, chaque carte d'erreur, et en secouant l'iPhone.

## Permissions

* Une seule action ouvre chaque permission du système qui manque, sur Mac, Windows et iOS.

## Équipes et automatisations

* Une équipe peut fixer le modèle et l'ordinateur de tous ses bots, avec une exception possible par bot.
* Un plugin Claude Code peut être importé comme une équipe complète.
* Une routine peut partir sur un événement GitHub (issue ouverte ou étiquetée, PR ouverte, revue demandée), avec des filtres par repo et par étiquette.
* Import d'un agent Hermes ; les sandboxes inactifs se mettent en veille.
* Les skills se révisent eux-mêmes et proposent leurs changements en un clic.

## Autres

* Mes appareils : chaque installation de Sagax, avec l'accès aux bots réglé par appareil.
* Traces OpenTelemetry, export OTLP et API de statistiques d'usage.
* Ultracode n'est offert qu'avec Claude Code ; les autres moteurs utilisent leur effort maximal.
* Les pull requests, branches et connecteurs sont dans l'onglet Coding du bot.
* Image d'environnement de codage avec cache de build Rust persistant.

## Avant de mettre à jour

Mets à jour le serveur Sagax en premier, puis l'app de bureau. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés.

## English

This release makes the app simpler for everyone: technical options move to Developer, the bot page is redesigned, and a shared Feedback bot sends a report in one click. It also adds coding teams (Claude Code plugin import, GitHub triggers) and one-step OS permission handling.

### Simplicity

* Every technical option (MCP, tokens, webhooks, logs, embeddings, working folder, zip export) now lives in Settings > Developer; each option has a single home.
* New bot page: clear rows that each open a sub-page, plus usage statistics by account, model, source and person.
* A "Shared" or "Partially shared" mark follows a bot's name in the sidebar.

### Feedback

* New shared Feedback bot: describe a problem or idea, check the anonymized preview, send in one click.
* Available from the sidebar footer, the Help menu (Cmd/Ctrl+Shift+F), `/feedback` in any chat, every error card, and by shaking the iPhone.

### Permissions

* One action opens every missing OS permission, on Mac, Windows and iOS.

### Teams and automations

* A team can set the model and computer for all its bots, with per-bot overrides.
* A Claude Code plugin can be imported as a full team.
* A routine can start on a GitHub event (issue opened or labeled, PR opened, review requested), filtered by repo and label.
* Hermes agent import; idle sandboxes hibernate.
* Skills revise themselves and propose changes in one click.

### Other

* My devices: every Sagax install, with bot access set per device.
* OpenTelemetry traces, OTLP export and a usage stats API.
* Ultracode is offered only with Claude Code; other engines use their maximum effort.
* Pull requests, branches and connectors live in the bot's Coding tab.
* Coding environment image with a persistent Rust build cache.

### Before updating

Update the Sagax server first, then the desktop app. Your bots, models, teams, plugins and personal settings are kept.
