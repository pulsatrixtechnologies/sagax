Sagax 0.5.28 est une version prioritaire : elle corrige les déconnexions, les plantages de mémoire du serveur, le réveil de l'environnement cloud et plusieurs régressions de 0.5.27.

## Fiabilité du serveur

* **Mémoire du serveur** : le nombre de sessions de moteur gardées au chaud est plafonné (4 sur un serveur Linux), la mémoire du serveur est surveillée et un moteur est sacrifié avant le serveur lui-même. Fini les plantages mémoire de fin de journée.
* **Session qui survit aux redémarrages** : après un arrêt non propre du serveur, votre connexion avec Pulsatrix est gardée et revérifiée auprès de Perspicax, au lieu de vous déconnecter.
* **Réveil de l'environnement cloud** : l'environnement est réveillé 12 minutes avant une routine, le démarrage est réessayé au lieu d'échouer, et le rapport d'une routine ne s'affiche qu'une fois.

## Bots et chat

* **Conversations bot à bot comme avant** : les cartes empilées en haut du chat disparaissent. Chaque échange revient en ligne discrète dans le fil, à sa place, dans le chat des deux bots.
* **Interrupteurs des routines** : chaque routine du panneau du bot a son interrupteur pour la mettre en pause ou la réactiver.
* **Section Coding** : vos branches de code ont leur carte, avec commit, push, PR, diff et archivage, sans jamais toucher la branche par défaut.
* **Salles créées par un bot** : une salle créée par un bot apparaît dans la barre latérale de sa personne.
* **Grandes mascottes** : elles retrouvent leur rendu d'avant 0.5.26.

## iOS

* Bouton Fils dans l'en-tête du chat, « Aller au message » qui bascule le chat en place, popup de réussite qui n'est plus traversée, brouillon iPad stable.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.28-arm64.dmg` ou `Sagax-0.5.28-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.28-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.5.28-win-x64.zip` et `Sagax-0.5.28-win-arm64.zip`.

## English

Sagax 0.5.28 is a priority release: it fixes sign-outs, server memory crashes, cloud environment wake-up and several 0.5.27 regressions.

* **Server memory**: warm engine sessions are capped (4 on a Linux server), server memory is watched, and an engine is sacrificed before the server itself. No more end-of-day memory crashes.
* **Session survives restarts**: after an unclean server stop, your Pulsatrix sign-in is kept and rechecked with Perspicax instead of signing you out.
* **Cloud environment wake-up**: the environment wakes 12 minutes before a routine, startup is retried instead of failing, and a routine report shows only once.
* **Bot-to-bot conversations like before**: the stacked cards at the top of the chat are gone. Each exchange is back as a quiet line in the thread, in place, in both bots' chats.
* **Routine switches**: each routine in the bot panel has a switch to pause or resume it.
* **Coding section**: your code branches have their own card, with commit, push, pull request, diff and archive, never touching the default branch.
* **Rooms created by a bot**: a room created by a bot shows in its person's sidebar.
* **Big mascots**: they get their pre-0.5.26 drawing back.
* **iOS**: Threads button in the chat header, "Go to message" switches the chat in place, the success popup no longer lets touches through, steady iPad draft.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
