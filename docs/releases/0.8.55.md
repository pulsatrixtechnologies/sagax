# Sagax 0.8.55

Version correctif rapide après la grosse 0.8.54. Les routines se lisent et s'ouvrent enfin comme il faut : un rapport de routine devient un message normal du bot, et un clic sur une routine ouvre son run. Le chat s'épure (en-tête, Linked Grok), les Réglages récupèrent des rangées et des liens perdus pendant la refonte, la page du bot aligne ses boutons sur le reste de l'app, et les moteurs Grok / Claude / Codex / Gemini / ACP gagnent des correctifs précis. Un bot peut écrire à une personne par un groupe. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

## Routines

* Un rapport de routine terminé se lit comme un message normal du bot dans le chat, au lieu d'une carte à part. PR #2169.
* Un clic sur une routine ouvre son run dans une fenêtre par-dessus le chat, depuis tous les points d'entrée (panneau du bot, carte du chat, liste des routines, calendrier, activité, notifications). La section Advanced reste toujours repliée à l'ouverture. PR #2275.

## Chat

* L'en-tête du chat ne montre plus que la pilule du nom : plus de libellé « Shared with », plus d'engrenage. PR #2262.
* Linked Grok quitte Réglages > Compte et se range sous Fournisseurs ; la recherche des Réglages suit le déplacement. PR #2262.

## Page du bot

* Le bouton X de la page du bot et la pilule Private / Shared utilisent la même primitive de bouton circulaire que le panneau du bot, le fil latéral et les autres en-têtes (même hauteur, même trait, même focus). PR #2269.

## Réglages

* **Modèles** : la colonne Backup (modèle de relève) reste toujours visible, même quand aucun bot n'a encore de relève. Une cellule vide affiche « None » ; un popover laisse choisir le moteur et le modèle. Le réglage bulk « Set backup » reste dans Modifier plusieurs. Sur la page Modèle d'un bot, Backup model, le réordonnancement et l'ajout restent utilisables même quand le défaut vient du serveur ou de l'organisation. PR #2270.
* **Organisation** : le lien « Gérer dans Perspicax » (pilule vers la console) revient sur la carte Organisation, pour les admins et pour les membres. PR #2264.
* **Sauvegardes** : la page ne propose plus l'import Grok Bot ni l'import des préférences du bot principal. L'import Grok Bot reste disponible dans les modèles de bots. PR #2266.

## Bots et personnes

* Un bot peut écrire à une autre personne de l'organisation avec l'outil `message_person` : il retrouve ou crée le groupe à trois (toi + la personne + le bot), publie dans le chat unifié, et propose la carte « Toujours permettre » pour cette personne. Les fils confidentiels restent refusés. PR #2251.

## Moteurs et Perspicax

* Quand plusieurs connecteurs gateway Perspicax exposent les mêmes outils agent Sagax (`send_prompt`, `await_turn`, `list_agents`, `sagax_*`), un seul exemplaire reste : celui du profil actif, sinon le premier. PR #2257.
* Le profil Perspicax actif du tour (act-as d'une routine, changement d'identité, `profile_use`) alimente le catalogue d'outils du gateway Grok : le connecteur de ce profil gagne. PR #2260.
* **Gemini** : les appels d'outils streamés arrivent entiers avec leur `id`, même sans `index`. PR #2256.
* **Codex** : un tour dont un outil a déjà tourné avant l'accusé `turn/start` n'est plus rejoué. PR #2256.
* **Claude Code** : les MCP tiers passent par ToolSearch, et l'opt-out est respecté. PR #2256.
* **Menu `/`** : les skills natifs des dossiers du moteur apparaissent dans le menu. PR #2256.
* **Stop ACP** : arrêter un tour tue l'hôte non partagé ; les steers openai-chat ne se perdent plus. PR #2256.
* **ACP personnalisé** : modèle et thinking se règlent par bot. PR #2256.
* **Questions Grok, Cursor et Pi** : les questions du bot s'affichent en cartes cliquables. PR #2256.
* Suite moteurs après le lot B : avis MCP Codex branchés, politiques d'outils régénérées, clés i18n experimental/settings resserrées (re-signature FR, replis périmés retirés). PR #2253.

## Sous le capot

* `ChatView` est découpé en shell et parts (session, transcript, stream, presence, shell, banners, header, rows, chips, …). Toutes les fonctions du chat passent sous le plafond de 400 lignes, sans changement visible. PR #2249.
* Ajustements de garde et d'indentation autour des tours openai-chat après le lot B, sans changement visible pour toi. PR #2253.
* Le packaging mac et Windows ne plante plus à l'étape after-pack (`pinnedOnePasswordVersion`). PR #2255.

## Avant de mettre à jour

Installe cette version sur le serveur Sagax, puis mets à jour l'app de bureau et l'app iOS. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés.

* Linked Grok se trouve maintenant sous Réglages > Fournisseurs.
* La page Sauvegardes n'offre plus l'import Grok Bot ni l'import des préférences du bot principal.
* L'en-tête du chat ne montre plus que la pilule du nom.

## English

A quick fix release after the large 0.8.54. Routines finally read and open the right way: a routine report becomes a normal bot message, and clicking a routine opens its run. The chat header is cleaner, Linked Grok moves to Providers, Settings regains rows and links lost in the redesign, the bot page aligns its buttons with the rest of the app, and Grok / Claude / Codex / Gemini / ACP engines get precise fixes. A bot can write to a person through a group. It covers the desktop app, the server, iPhone and iPad.

### Routines

* A finished routine report reads as a normal bot message in the chat instead of a separate card. PR #2169.
* Clicking a routine opens its run in a window over the chat from every entry point (bot panel, chat card, routine list, calendar, activity, notifications). The Advanced section always starts collapsed. PR #2275.

### Chat

* The chat header shows only the name pill: no "Shared with" label, no gear. PR #2262.
* Linked Grok leaves Settings > Account and lives under Providers; Settings search follows the move. PR #2262.

### Bot page

* The bot page close X and the Private / Shared pill use the same circular button primitive as the bot panel, the side thread and other headers (same height, stroke and focus). PR #2269.

### Settings

* **Models**: the Backup (fallback model) column stays visible even when no bot has a backup yet. An empty cell shows "None"; a popover picks the engine and model. Bulk "Set backup" stays in Edit several. On a bot's Model page, Backup model, reorder and add stay usable even when the default comes from the server or the organization. PR #2270.
* **Organization**: the "Manage in Perspicax" link (pill to the console) returns on the Organization card for admins and members. PR #2264.
* **Backups**: the page no longer offers Grok Bot import or primary-bot preference import. Grok Bot import stays in bot models. PR #2266.

### Bots and people

* A bot can write to another organization person with `message_person`: it finds or creates the triad group (you + the person + the bot), posts in the unified chat, and offers an "Always allow" card for that person. Confidential threads stay refused. PR #2251.

### Engines and Perspicax

* When several Perspicax gateway connectors expose the same Sagax agent tools (`send_prompt`, `await_turn`, `list_agents`, `sagax_*`), only one copy remains: the active profile's, otherwise the first. PR #2257.
* The turn's active Perspicax profile (routine act-as, identity switch, `profile_use`) feeds the Grok gateway tool catalog: that profile's connector wins. PR #2260.
* **Gemini**: streamed tool calls arrive whole with their `id`, even without an `index`. PR #2256.
* **Codex**: a turn whose tool already ran before the `turn/start` ack is not replayed. PR #2256.
* **Claude Code**: third-party MCP goes through ToolSearch, and the opt-out is respected. PR #2256.
* **`/` menu**: native skills from the engine folders appear in the menu. PR #2256.
* **Stop ACP**: stopping a turn kills the non-shared host; openai-chat steers are kept. PR #2256.
* **Custom ACP**: model and thinking are set per bot. PR #2256.
* **Grok, Cursor and Pi questions**: bot questions show as clickable cards. PR #2256.
* Engines follow-up after lot B: Codex MCP notices wired, tool policies regenerated, experimental/settings i18n tightened. PR #2253.

### Under the hood

* `ChatView` is split into a shell and parts. Every chat function stays under the 400-line ceiling, with no visible change. PR #2249.
* Guard and indentation fixes around openai-chat turns after lot B, with no visible change for you. PR #2253.
* Mac and Windows packaging no longer crashes in the after-pack step (`pinnedOnePasswordVersion`). PR #2255.

## Before you update

Install this version on the Sagax server, then update the desktop and iOS apps. Your bots, models, teams, plugins and personal settings are kept. Linked Grok now lives under Settings > Providers. The Backups page no longer offers Grok Bot import or primary-bot preference import. The chat header shows only the name pill.
