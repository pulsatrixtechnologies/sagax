Sagax 0.6.0 rend les bots plus sûrs, plus rapides et plus autonomes : connexion GitHub par code, secours automatique de moteur, réglages que les bots peuvent modifier, et un navigateur de bots mieux protégé.

## Connexions

* **GitHub par code, depuis le chat** : demandez à un bot de se connecter à GitHub. Il affiche un code et un lien, vous confirmez sur GitHub, et c'est fait, sans copier de jeton.
* **Sites avec le coffre** : un bot peut se connecter à un site (même en plusieurs étapes) avec vos identifiants du coffre, sans jamais voir le mot de passe.

## Moteurs

* **Secours automatique** : quand un moteur atteint sa limite d'usage, Sagax bascule sur un autre moteur disponible et poursuit la conversation.
* **Parité des moteurs** : « Approuver pour moi » décide maintenant dans Sagax avec Grok, les outils Browser et Data de pi passent par l'approbation Sagax, et les images fonctionnent avec Grok 1.x récent.
* **Corrections** : plusieurs bogues de Codex, des moteurs, du navigateur, du bureau, des fils et des routines sont corrigés.

## Bots

* **Tout réglage est une action** : un bot peut lire et modifier les réglages de Sagax pour vous, avec les approbations habituelles.
* **Plus rapide, moins de jetons** : appels ponctuels isolés, outils inutiles retirés, images de documents Office en entrée directe, reprise d'un tour d'équipier sans relancer le moteur.

## Sécurité

* **Navigateur des bots** : une page web locale ne peut plus créer de bot ni piloter le navigateur, le port de contrôle du compagnon exige un jeton, et la sortie du navigateur est filtrée (les adresses internes sont bloquées). Pour les développeurs seulement : lancer l'app non empaquetée demande maintenant de connecter sa fenêtre.

## Interface

* **Menu du compte** : Approbations et Code s'y trouvent maintenant.
* **Barre latérale repliée** : une seule icône Connect apps, plus de défilement horizontal, bot épinglé centré, et l'avatar ouvre le menu du compte.
* **Apparence** : variantes de couleur par famille, couleurs pleines, duo-tons, ambiances, textures et éditions Windows pour Hibou 98.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.6.0-arm64.dmg` ou `Sagax-0.6.0-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.6.0-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.6.0-win-x64.zip` et `Sagax-0.6.0-win-arm64.zip`.

## English

Sagax 0.6.0 makes bots safer, faster and more autonomous: GitHub sign-in by code, automatic engine backup, settings bots can change, and a better protected bot browser.

* **GitHub by code, from the chat**: ask a bot to connect to GitHub. It shows a code and a link, you confirm on GitHub, done, with no token to copy.
* **Sites with the vault**: a bot can sign in to a website (even multi-step) with your vault logins, without ever seeing the password.
* **Automatic backup engine**: when an engine hits its usage limit, Sagax switches to another available engine and carries on.
* **Engine parity**: "Approve for me" now decides inside Sagax with Grok, pi's Browser and Data tools go through Sagax approval, and images work with recent Grok 1.x.
* **Fixes**: several Codex, engine, browser, desktop, thread and routine bugs are fixed.
* **Every setting is an action**: a bot can read and change Sagax settings for you, with the usual approvals.
* **Faster, fewer tokens**: isolated one-off calls, unused tools removed, Office document images passed directly, teammate replies resume the turn without restarting the engine.
* **Bot browser security**: a local web page can no longer create a bot or drive the browser, the companion control port requires a token, and the browser's outbound traffic is filtered (internal addresses are blocked). Developers only: launching the unpackaged app now asks you to connect its window.
* **Account menu**: Approvals and Code now live there.
* **Collapsed sidebar**: a single Connect apps icon, no horizontal scrolling, the pinned bot centered, and the avatar opens the account menu.
* **Appearance**: color variants per family, solid colors, duotones, moods, textures and Windows editions for Hibou 98.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
