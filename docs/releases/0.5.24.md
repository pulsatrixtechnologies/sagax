Sagax 0.5.24 débloque les membres d'une organisation : leur bot travaille sur leurs propres ordinateurs et lit les pièces jointes qu'ils envoient sans attendre un administrateur. Elle apporte aussi des correctifs de sécurité et prépare la section Code des agents cloud.

## Membres d'une organisation

* **Vos propres destinations, sans administrateur** : quand votre bot veut lancer une commande sur votre ordinateur, votre VM locale ou votre ordinateur infonuagique, c'est vous qui approuvez la carte, à votre niveau. Un administrateur n'est plus sollicité pour ce qui se passe chez vous.
* **Pièces jointes lues directement** : un fichier que vous envoyez (un .zip, par exemple) est listé et lu par votre bot sans carte d'approbation.
* **Terminal** : vos propres destinations s'ouvrent depuis toute conversation à vous, bot partagé compris.
* **Commandes sur le serveur de l'organisation** : elles demandent une nouvelle permission, « Exécuter des commandes sur le serveur de l'organisation » (`host.commands`). Un administrateur la donne dans Perspicax, **Droits sur les bots > Qui a quoi** (à une personne ou une équipe), ou dans un jeu de permissions.
* **Refus clairs** : quand une action exige encore un administrateur, le message dit quoi demander et à qui.

## Sécurité

* Les secrets sont masqués dans la mémoire d'équipe, y compris les entrées déjà enregistrées.
* Un bot supprimé ne laisse plus d'état d'entretien de mémoire.
* Une session Claude dont l'authentification a échoué est fermée au lieu de bloquer les autres bots.
* Les clés Stripe sont masquées.

## Ordinateur

* **Section Code (agents cloud)** : la nouvelle section Code montre les runs des agents cloud de votre organisation, leur conversation, leurs changements et leurs commits. Elle n'apparaît que lorsque le serveur Perspicax de votre organisation prend les agents cloud en charge ; sinon, elle reste masquée.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.24-arm64.dmg` ou `Sagax-0.5.24-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.24-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.5.24-win-x64.zip` et `Sagax-0.5.24-win-arm64.zip`.

## English

Sagax 0.5.24 unblocks organization members: their bot works on their own computers and reads the attachments they send without waiting for an administrator. It also brings security fixes and prepares the Code section for cloud agents.

* **Your own destinations, no administrator** (members): when your bot wants to run a command on your computer, your local VM or your cloud computer, you approve the card, at your level. An administrator is no longer asked about what happens on your own machines.
* **Attachments read directly** (members): a file you send (a .zip, for example) is listed and read by your bot without an approval card.
* **Terminal** (members): your own destinations open from any conversation of yours, shared bots included.
* **Commands on the organization's server** (members): they need a new permission, "Run commands on the organization's server" (`host.commands`). An administrator grants it in Perspicax, **Bot permissions > Who has what** (to a person or a team), or in a permission set.
* **Clear refusals** (members): when an action still needs an administrator, the message says what to ask for and whom.
* **Security**: secrets are masked in team memory (including entries already saved), a deleted bot leaves no memory upkeep state behind, a Claude session whose sign-in failed is closed instead of blocking other bots, and Stripe keys are masked.
* **Code section (cloud agents)** (computer): the new Code section shows your organization's cloud agent runs, their conversation, changes and commits. It appears only when your organization's Perspicax server supports cloud agents; otherwise it stays hidden.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
