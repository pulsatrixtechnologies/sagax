# Sagax 0.8.54

Grosse version. Les bots gagnent le téléphone, un pont signé vers ton propre Grok, la possibilité d'écrire à une personne par un groupe, les GIF et les mèmes. Les Réglages sont refaits page par page, sans carte dans une carte. Le panneau et le profil du bot s'alignent sur Grok Bot. Les comptes d'un même fournisseur tournent sans bruit avant la limite. Quatre lots de correctifs de l'amont arrivent (sécurité, pleins pouvoirs, deux lots de moteurs), et une passe de performance fait écrire moins pendant que le bot travaille. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

## Les bots et les personnes

### Un bot écrit à une personne par un groupe

* Un bot peut maintenant écrire directement à une autre personne du serveur avec le nouvel outil `message_user`.
* Il cherche d'abord un groupe qui réunit déjà toi, la personne et le bot ; s'il n'y en a pas, il le crée (toi + la personne + le bot) et écrit là.
* Tout reste dans le chat unifié : aucun fil séparé, aucun panneau de fil. La carte d'approbation offre « Toujours permettre ».
* Pas de groupe fantôme : le groupe n'est créé qu'au moment d'écrire. Une personne invitée peut seulement quitter le groupe.
* Issue #2118.

### GIF et mèmes dans le chat

* Un sélecteur de GIF avec recherche arrive dans la barre de tous les chats : bot, personne et groupe. Tu peux aussi coller ou glisser un fichier .gif.
* Les bots peuvent répondre par un GIF ou un mème (outil `send_meme`) quand ta façon d'écrire s'y prête : si tu en envoies, ou si le ton est léger. Le choix suit la personnalité du bot.
* Issue #2121.

### Pont Grok personnel, signé, propre à chaque personne

* Chaque personne peut lier son propre compte Grok (Réglages > Compte) : URL du webhook, clé scellée dans ton coffre, interrupteur, noms des pairs et bouton de test.
* Tes bots Sagax et tes bots Grok se parlent dans les deux sens. Les messages sortants sont signés (HMAC, enveloppe v1), protégés contre le rejeu (fenêtre, nonces, idempotence), limités en débit et coupés par un disjoncteur en cas d'erreurs répétées. Une file d'envoi fait trois essais, et les messages qui échouent encore vont dans une file d'erreurs.
* Nouveaux outils : `grok_send`, `bridge_claim`, `bridge_release`, `bridge_list_leases`.
* Une réponse arrive dans le chat unifié du bot de la personne, encadrée, jamais dans un fil séparé.
* Un bot ne peut joindre que les bots Grok de sa propre personne. Un message reçu par le pont est de l'information, jamais un GO.
* Les admins de l'organisation ont un interrupteur global dans Réglages > Organisation.
* Issue #2193.

### Téléphone : parité avec Grok Bot

* Les bots Sagax passent par Perspicax Voice, comme Grok Bot.
* Le bot répond aux textos sur ton numéro, prend tes appels, te rappelle avec ses questions et peut joindre tes contacts de ligne (`phone_line_contact`, `phone_call_owner`).
* Ton bot Grok peut déclencher ces actions par le pont (#2193). Le numéro du propriétaire vient de « Me joindre » quand il est rempli.
* Issue #2194.

### Équipes : chacun chez soi

* Chaque membre voit et gère seulement SES équipes, SES bots et SON bot principal. Les équipes des autres disparaissent de ta vue sans être supprimées.
* La Team map reflète les groupes de ta barre latérale (une seule source), avec des sous-équipes jusqu'à 4 niveaux.
* Un membre gère ses propres équipes sur un serveur d'organisation sans passer par un admin.
* La liste des ordinateurs d'équipe ne montre que les tiens (plus ceux qui ne sont pas assignés), et on ne peut plus assigner un ordinateur à l'équipe d'une autre personne.
* Le nom suggéré d'un nouveau bot est propre à chaque personne.
* Issue #2045.

### GitHub : un lien et un code, depuis n'importe quel chat

* Pour connecter GitHub, une carte de connexion apparaît dans le chat : un lien et un code d'appairage, sans passer par un admin.
* Le jeton personnel reste disponible sous Avancé.
* Issue #2109.

### Pages : plus d'attente d'un admin

* Créer une page n'attend plus l'approbation d'un admin de l'organisation : le choix de l'endroit (`choose_page_target`) relève de la personne. Issue #2199.

## Réglages

* **Refonte niveau 3, façon Grok Bot** : chaque page est repassée pour être simple, avec un état et une action par rangée. Aucune information n'est retirée : le détail reste derrière un clic. Issue #2080.
* **Organisation** : bandeau d'organisation, règles d'org en lecture seule pour les membres, interrupteur du pont Grok, aucun raccourci Perspicax en double.
* **Ordinateur** : le navigateur (Mon Chrome) est réglé ici ; le libellé « Entretien de l'ordinateur » revient sur iPad comme sur le bureau.
* **Sauvegardes** : visibles par les membres. L'import devient une carte simple.
* **Expérimental** : liste de bascules simples. Le modèle de décision quitte cette page.
* **Mises à jour** : une rangée « Sagax {version} » avec son état, le canal et le mode absent raccourcis, et une carte Liens (notes de version, À propos).
* **Voix** : la carte Appels téléphoniques est la même pour tout le monde, en lecture seule. Les appels téléphoniques de l'organisation se règlent maintenant dans Perspicax.
* **App** : l'installation temporaire passe en sections Avancé sœurs, sans carte dans une carte. « Workspace » devient « Espace de travail » en français.
* **Aucune carte dans une carte** : Modèles > Avancé devient un titre avec pastille, et son contenu se déplie en sections sœurs. Un scan headless de 124 vues ne trouve aucune imbrication, et des tests gardes empêchent le retour. Issue #2175.
* **Menus simplifiés (passe JC)** : replis Avancé, tutoiement partout. Issue #2093.

## Panneau et profil du bot

* **Profil du bot** : bannière de 145 px à la couleur de la mascotte, colonne de 1000 px comme Grok Bot, réglages en onglets en haut à côté de Général et Connaissances, plus d'engrenage. Issue #2173.
* **Carte Ordinateur** : un clic ouvre directement le bureau en direct (Watching ou You have control). Un menu dans l'en-tête change l'ordinateur du bot : Auto, cet ordinateur, Infonuagique ou Désactivé. Issue #2187.
* **À venir** : 5 routines puis « Afficher plus », comme Grok Bot. Issue #2174.
* **Mascotte** : la mascotte du haut du panneau prend la taille de Grok Bot. Issue #2196.

## Chat et modèles

* **Sélecteur de modèle** : 30 % moins haut (392 px au plus) ; le pied Effort et Fournisseurs reste toujours visible ; 4 modèles au plus par fournisseur, puis « Afficher plus ». Issue #2181.
* **Rotation des comptes avant la limite** : quand tu as plusieurs comptes chez le même fournisseur, Sagax passe sans bruit au compte qui a le plus de marge, dès 90 % d'usage. Une réponse vide est relancée une fois sur le compte suivant. Les bascules restent dans Événements ; le chat ne t'avertit que lorsque tous les comptes sont épuisés. Issue #2192.
* **Noms d'outils stables** : quand deux serveurs MCP exposent les mêmes noms (`send_prompt`, `api_search`...), un seul les sert. Le chat ne voit plus le nom changer d'un appel à l'autre. Une connexion en double (deux GitHub, deux Superpowers) n'apparaît plus deux fois dans Capacités. Le bot sait que les noms d'outils notés dans sa mémoire peuvent être périmés et que sa liste d'outils actuelle fait foi. Issue #2189.
* **Outils Perspicax perdus** : sur une délégation, un réveil par un coéquipier ou la reprise d'une carte, le bot gardait mal qui parlait et perdait ses outils Perspicax (`unknown_speaker`). Il garde maintenant la bonne personne, ou le propriétaire pour une routine. Issue #2191.

## Routines

* Le widget d'une routine est dessiné comme dans le chat, plus en code brut, et la coupe d'un rapport ne tranche plus un widget au milieu. Issue #2186.

## Lots repris de l'amont

### Sécurité (#2110)

* Les bots demandent tout secret par la carte sécurisée : référence à usage unique ou fichier privé, avec raison et option « sur cet ordinateur seulement ».
* La carte de secret garde son champ sur une page ouverte par un bureau jumelé.
* Les clés d'API SendGrid sont masquées dans les journaux et le chat, et s'ajoutent aux jetons GitLab et aux clés temporaires AWS déjà masqués.
* Dépendances mises à jour selon les avis de sécurité publiés.

### Pleins pouvoirs et approbations en direct (#2111)

* Full access s'active tout de suite, de n'importe quel client, sans confirmation. Les bots démarrent en Full access.
* En Full access, le bot envoie par tes apps connectées sans redemander. Lire ses propres fichiers ne demande rien.
* Le niveau d'accès suit chaque relais entre bots et peut changer pendant que le bot travaille.
* Les fonctions de Sagax gardent la priorité : chat unifié, « Toujours permettre », cartes de mémoire d'équipe.

### Moteurs, lot A (#2113)

* Nouveaux moteurs : DeepSeek et GitHub Copilot, à côté de Meta et museCode.
* Le modèle d'aide sert aussi à l'entretien de la mémoire.
* Les skills personnelles de Claude sont reprises.
* Les schémas des outils MCP sont ajustés à chaque moteur.

### Moteurs, lot B (#2114)

* Un bot Claude qui atteint sa limite d'usage continue avec un autre modèle disponible au lieu de s'arrêter.
* Claude ne reste plus bloqué sur une fenêtre pleine pendant que son usage supplémentaire payé est disponible.
* Gemini : la signature de réflexion est renvoyée avec ses appels d'outils, ce qui évite les échecs en plein travail.
* Un bot qui a contourné un outil en échec termine son tour proprement, sans rester en erreur.
* Une vérification de connexion illisible laisse le compte non connecté au lieu de le croire actif.
* Connexion Grok Build ACP corrigée pour la version actuelle de l'outil en ligne de commande.
* OpenRouter et les autres modèles à clé d'API respectent la limite de 128 outils.
* Une seule liste d'outils par rôle : un nouveau bot de ce rôle répond tout de suite.
* Un tour ne démarre qu'une fois ses serveurs MCP prêts.
* Les appels d'outils d'un modèle local fonctionnent même s'ils arrivent dans un format inattendu.
* Un tour dont toute la réponse est une erreur du fournisseur est marqué en échec, plus affiché comme une réponse.
* Les vidéos jointes sont découpées en images pour les modèles de vision.
* Claude peut poser une question structurée par MCP (élicitation), avec le marqueur Full access sur la carte. Codex affiche les avis MCP.

### Performance, mémoire et fiabilité (#2112)

* Le serveur écrit moins pendant que le bot travaille : écritures groupées et fenêtre client de 14 jours.
* Les petites mascottes tournent à 20 images par seconde.
* Les sessions Claude et ACP inactives se ferment d'elles-mêmes.
* Les autres correctifs du lot étaient déjà dans Sagax.

### Synchronisation

* Synchronisation avec la version amont 0.1.107. Issue #1913.

## Avant de mettre à jour

Installe cette version sur le serveur Sagax, puis mets à jour l'app de bureau et l'app iOS. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés.

* Les bots démarrent maintenant en Full access.
* Les équipes créées par d'autres membres disparaissent de ta vue ; elles ne sont pas supprimées.
* Certaines pages de Réglages changent de place.
* Les appels téléphoniques de l'organisation se règlent dans Perspicax, plus dans Sagax.

## English

A big release. Bots get the phone, a signed bridge to your own Grok, the ability to write to a person through a group, and GIFs and memes. Settings are redone page by page, with no card inside a card. The bot panel and profile align with Grok Bot. Accounts of the same provider rotate silently before the limit. Four upstream batches land (security, full access, two engine batches), and a performance pass makes the server write less while a bot works. It covers the desktop app, the server, iPhone and iPad.

### Bots and people

* **A bot writes to a person through a group** (`message_user`): it reuses the you + person + bot group, or creates it when it writes. Everything stays in the unified chat, with an "Always allow" card. Issue #2118.
* **GIFs and memes**: GIF picker with search in every chat, plus paste or drop a .gif. Bots can answer with a GIF or meme (`send_meme`) when your tone invites it. Issue #2121.
* **Personal signed Grok bridge**: link your own Grok account in Settings > Account. Messages are signed with HMAC and protected by a replay window, rate limits and a circuit breaker; failed sends retry three times, then go to a dead-letter queue. New tools `grok_send` and `bridge_*`. A bot only reaches its own person's Grok bots. Bridge messages are information, never a GO. An org admin kill switch is available. Issue #2193.
* **Phone parity**: Sagax bots run on Perspicax Voice. They answer your texts, take your calls, call you back and reach your line contacts; your Grok bot can trigger these through the bridge. Issue #2194.
* **Teams, per person**: you only see and manage your own teams, bots and primary bot. The Team map follows your sidebar groups, with sub-teams. Members manage their own teams without an admin, and team computers are scoped per person. Issue #2045.
* **GitHub**: connect with a link and a pairing code from any chat; the token stays under Advanced. Issue #2109.
* **Pages**: creating a page no longer waits for an org admin. Issue #2199.

### Settings

* Level 3 redesign of every page: one state and one action per row, with nothing removed. Covers Organization, Computer (My Chrome), Backups (member visible), Import as a simple card, Experimental as toggles, Updates (one "Sagax {version}" row, a Links card), Voice (phone calls read-only for everyone; org phone calls are now edited in Perspicax) and App (temporary install as Advanced sections). Issue #2080.
* No card inside a card: Models > Advanced unfolds as sibling sections. A headless scan of 124 views found 0 nesting, and guard tests keep it that way. Issue #2175.
* Simplified menus. Issue #2093.

### Bot panel and profile

* Mascot-colour banner, 1000 px column, settings as top tabs, no gear. Issue #2173.
* Computer card opens the live desktop, with a menu to pick the computer. Issue #2187.
* Upcoming shows 5 routines, then "Show more". Issue #2174.
* Grok Bot sized mascot. Issue #2196.

### Chat and models

* Model picker 30% shorter, footer always visible, 4 models per provider. Issue #2181.
* Silent rotation across accounts of one provider from 90% usage; an empty reply is retried once. You are told only when every account is spent. Issue #2192.
* Stable tool names when two MCP servers overlap, with no duplicate rows in Capabilities; memory notes defer to the live tool list. Issue #2189.
* Perspicax tools are no longer dropped on delegation, wake-ups or card resumes. Issue #2191.

### Routines

* Routine widgets render like in the chat, never cut in half. Issue #2186.

### Upstream batches

* **Security** (#2110): the secure secret card asks for a one-use ref or a private file; SendGrid keys are masked; dependency advisories are fixed.
* **Full access** (#2111): Full access turns on at once and is the default for bots. It sends through connected apps without asking, carries the level across relays and lets the level change mid-work.
* **Engines A** (#2113): DeepSeek and GitHub Copilot engines, helper model for memory upkeep, Claude user skills, per-engine MCP schema fit.
* **Engines B** (#2114): a Claude bot at its usage limit carries on with another model; no hold at a full window while paid extra usage is available; Gemini thought signatures sent back with tool calls; clean end after working around a failed tool; unreadable sign-in checks leave the account disconnected; Grok Build ACP sign-in fixed; OpenRouter and API-key models fit the 128-tool limit; one tool list per role; turns wait for their MCP servers; local model tool calls parsed in odd formats; provider-error replies fail the turn; attached videos sampled into frames for vision models; Claude MCP elicitation with the Full access marker, and Codex MCP notices.
* **Performance** (#2112): fewer writes while a bot works, small mascots at 20 fps, idle Claude and ACP sessions close.
* Sync with upstream 0.1.107. Issue #1913.

## Before you update

Install this version on the Sagax server, then update the desktop and iOS apps. Your bots, models, teams, plugins and personal settings are kept. Bots now start in Full access. Teams created by other members leave your view without being deleted. Some Settings pages move.
