Sagax 0.8.156 refait les cartes X publiées (vrai compte, look X, pile pour plusieurs publications), note la réponse de chaque canal pour ne plus dire « envoyé » après un envoi raté, et corrige la montre Apple pour de vraies montres.

### Ce que tu remarques d'abord

* **Une carte X publiée montre le vrai compte et ressemble à X (#4894)**, et plusieurs publications d'un même tour forment une pile.
* **Un envoi raté n'est plus annoncé comme envoyé (#4755)**.
* **L'app Apple Watch se construit pour de vraies montres (#4896)**.

### Chat

* **Les cartes X publiées (#4894, #4897)** : une publication affiche le compte qui a publié, appris aussi depuis la session x.com connectée, (photo gardée en cache, nom, badge, identifiant), en une seule carte à la typographie de X, avec le contexte de réponse, la rangée d'actions, le logo X et la pastille « Publié ». Plusieurs publications d'un même tour s'empilent comme dans iMessage : glisse, utilise les flèches ou déplie la pile.
* **La réponse de chaque canal est notée (#4755)** : un envoi qui échoue n'est plus noté comme annoncé, donc une vérification plus tard ne croit plus la personne déjà jointe. Un texto ou un message WhatsApp n'est quand même jamais envoyé deux fois, et une notification push garde sa seule reprise.

### Apple Watch

* **L'app de la montre se construit pour de vraies montres (#4896)** : la construction de l'archive échouait sur la cible de la montre (Int de 32 bits). Le plafond de l'ordinateur est ramené au maximum permis, et les valeurs de repère des archives zip sont comparées en 64 bits.

### Interne

* **L'empaquetage macOS ne signe que le code (#4891)**.

## Avant de mettre à jour

Si tu héberges Sagax toi-même, garde une copie de tes données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.156 redoes the posted X cards (real account, X look, a stack for several posts), records each channel's answer so a failed send is no longer reported as sent, and fixes the Apple Watch app for real watches.

### What you notice first

* **A posted X card shows the real account and looks like X (#4894)**, and several posts of one turn form a stack.
* **A failed send is no longer reported as sent (#4755)**.
* **The Apple Watch app builds for real watches (#4896)**.

### Chat

* **Posted X cards (#4894, #4897)**: a post shows the account that posted, learned also from the signed-in x.com session, (cached picture, name, badge, handle), as one card with X typography, reply context, the action row, the X logo and a Posted chip. Several posts of one turn stack like iMessage: swipe, use the arrows or expand the stack.
* **Each channel's answer is recorded (#4755)**: a send that fails is no longer recorded as told, so a later check no longer assumes the person was reached. A text or a WhatsApp message is still never sent twice, and a push keeps its one retry.

### Apple Watch

* **The watch app builds for real watches (#4896)**: the archive build failed on the watch target (32-bit Int). The desktop cap is clamped to the largest allowed value, and zip sentinel values are compared as 64-bit.

### Internal

* **macOS packaging signs only code (#4891)**.

## Before you update

If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
