# Bot models page (#1675)

Headless captures of Settings > Models > Bot models. Synthetic gallery data
only (`src/gallery/settings-pages.html?section=engines&org=1&providers=1`).

Generated by:

```bash
node scripts/capture-bot-models-page.mjs --width 1338 --prefix after
node scripts/capture-bot-models-page.mjs --width 700 --prefix after-narrow
```

Sizes: 1338 (desktop) and 700 (narrow). One shared `table-fixed` + `colgroup`
so Engine / Effort / Who pays / Backup line up across sidebar sections.

| Shot | File | What it shows |
|---|---|---|
| Page | `after-1-page.png` | Defaults (when solo) and the shared bots table with section header rows |
| Section selected | `after-2-section-selected.png` | Whole Clients section selected, bulk bar visible |
| Bulk confirm | `after-3-bulk-confirm.png` | Confirmation summary before applying Auto to the selection |
| Narrow page | `after-narrow-1-page.png` | Same page at 700px width |

`after-capture.json` / `after-narrow-capture.json` record DOM facts (row ids,
sections, bulk lines, shared table, column alignment across sections).

No live user data. No `.ref/` third-party captures.
