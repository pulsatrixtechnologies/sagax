Sagax 0.5.29 rend les widgets du bot plus fiables, simplifie le choix de l'ordinateur pour les membres et prépare les agents cloud personnels.

## Widgets

* **Cases à cocher et libellés** : un widget interactif n'écrase plus ses libellés (un mot par ligne) et les curseurs ne se chevauchent plus.
* **Le bot valide ses widgets** : avant d'en montrer un, le bot le fait vérifier (erreurs, texte coupé, contraste, cibles trop petites, bureau et téléphone, clair et sombre) et le corrige. Après trois essais, il l'affiche avec la mention discrète « Affichage imparfait ».

## Membres et ordinateur

* **Choisir son ordinateur sans carte** : quand le bot choisit où il travaille parmi vos propres ordinateurs, plus aucune carte ni demande à un administrateur. Les commandes lancées ensuite gardent leurs règles.
* **Onglet Computer** : il s'ouvre sur la destination que le bot utilise pour le fil (le nuage tant qu'elle n'est pas connue), plus sur le Mac par habitude.

## Agents cloud

* **Abonnement moteur** : un agent cloud personnel peut utiliser votre abonnement de moteur, remis à Perspicax de façon sécurisée. Sans connexion ni clé, le lancement est refusé avec la raison.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.29-arm64.dmg` ou `Sagax-0.5.29-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.29-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.5.29-win-x64.zip` et `Sagax-0.5.29-win-arm64.zip`.

## English

Sagax 0.5.29 makes bot widgets more reliable, simplifies the computer choice for members and prepares personal cloud agents.

* **Checkboxes and labels**: an interactive widget no longer squashes its labels (one word per line) and sliders no longer overlap.
* **The bot validates its widgets**: before showing one, the bot has it checked (errors, cut text, contrast, tiny targets, desktop and phone, light and dark) and fixes it. After three tries it shows it with a quiet "Imperfect display" note.
* **Choosing your computer without a card**: when the bot picks where it works among your own computers, there is no card and no admin request. Commands run afterwards keep their rules.
* **Computer tab**: it opens on the destination the bot is using for the thread (Cloud until it is known), not the Mac by habit.
* **Cloud agents**: a personal cloud agent can use your engine subscription, handed to Perspicax securely. Without a connection or key, the launch is refused with the reason.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
