# Sagax 0.8.38

Correctif serveur : un profil Perspicax au nom long reste branché sur les moteurs Claude et Codex.

### Perspicax

* Un profil Perspicax dont le nom de serveur dépasse 32 caractères n'est plus retiré de la configuration MCP des moteurs Claude et Codex. Le bot voit de nouveau les outils de ce profil, au lieu d'un serveur annoncé mais sans outils.
* Sur une consigne compacte, un profil Perspicax liste ses outils essentiels au complet (recherche, description, lecture des résultats et ses outils de lecture et d'écriture).
* Une réponse de la passerelle Perspicax nomme le serveur du profil qui exécute ses outils, et un appel vers un outil de profil trouve ce serveur au lieu de répondre qu'aucun outil ne porte ce nom.

## Avant de mettre à jour

Rien à préparer. Ce correctif touche seulement le serveur : l'app de bureau et l'app iOS restent sur 0.8.36. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image.

## English
<!-- date: 2026-11-03 -->
Server fix: a Perspicax profile with a long name stays connected on the Claude and Codex engines.

### Perspicax

* A Perspicax profile whose server name is over 32 characters is no longer dropped from the MCP configuration of the Claude and Codex engines. The bot sees that profile's tools again, instead of a server that is listed but has no tools.
* On a compact prompt, a Perspicax profile lists its core tools in full (search, describe, reading results, and its read and write tools).
* A Perspicax gateway answer names the profile server that runs its tools, and a call to a profile tool finds that server instead of answering that no tool has that name.

## Before you update

Nothing to prepare. This fix touches only the server: the desktop and iOS apps stay on 0.8.36. If you self-host Sagax, keep a copy of your data (`docs/self-hosting.md`) before replacing the image.
