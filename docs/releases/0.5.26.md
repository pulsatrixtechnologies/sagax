Sagax 0.5.26 débloque le choix du modèle d'un membre quand une approbation de bot à bot attend, aligne le panneau « This run » sans jamais montrer d'identifiant technique, et masque proprement la section Code quand le serveur refuse l'accès.

## Membres d'une organisation

* **Modèle de vos bots** : un bot dont le modèle restait grisé sur « Auto » parce qu'un autre de vos bots lui avait délégué du travail peut de nouveau changer de modèle. Les approbations bot à bot qui vous attendent apparaissent maintenant dans la boîte d'approbation de la conversation ouverte, avec la mention « Demandée par » suivie du nom du bot. Vous pouvez les accepter, les refuser ou « Toujours permettre ».
* **Raison claire** : dans Modifier le bot, le modèle n'est verrouillé que par la conversation sélectionnée, avec la raison en clair (une approbation vous attend, une approbation attend un administrateur, ou la conversation travaille) et un bouton « Ouvrir la conversation ».
* **Aucun moteur accessible** : si votre organisation ne vous a donné aucun moteur, le menu du modèle explique quoi faire (ajouter votre clé ou votre abonnement, ou demander un moteur à un administrateur) au lieu d'une liste réduite à « Auto ».

## Ordinateur

* **Panneau « This run »** : même colonne, même rayon et même fond que Environment, Context et Connectors, en clair comme en sombre.
* **Plus d'identifiant visible** : Environment affiche « Dossier de cette conversation », et les comptes, personnes, bots, équipes, moteurs retirés, ordinateurs infonuagiques orphelins, dossiers, voix, journal et erreurs de serveur utilisent des libellés lisibles. Les chemins complets restent en info-bulle seulement.
* **Section Code** : quand Perspicax refuse l'accès à l'API des agents (401 ou 403), la section Code disparaît au lieu d'afficher « Perspicax answered 401. ».

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.5.26-arm64.dmg` ou `Sagax-0.5.26-x64.dmg` et glissez Sagax dans Applications. Signée (Developer ID) et notariée par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.5.26-setup.exe`. Non signé : SmartScreen affiche un éditeur inconnu ; choisissez **Informations complémentaires**, puis **Exécuter quand même**. Versions portables : `Sagax-0.5.26-win-x64.zip` et `Sagax-0.5.26-win-arm64.zip`.

## English

Sagax 0.5.26 unblocks a member's model choice when a bot-to-bot approval is waiting, lines up the "This run" panel without ever showing a technical identifier, and hides the Code section cleanly when the server refuses access.

* **Your bots' model** (members): a bot whose model stayed greyed out on "Auto" because another of your bots had delegated work to it can change model again. Bot-to-bot approvals waiting on you now show in the open conversation's approval box, marked "Requested by" the bot's name. You can accept, refuse or "Always allow" them.
* **A clear reason**: in Edit bot, the model is locked only by the selected conversation, with the reason in plain words (an approval waits for you, an approval waits for an administrator, or the conversation is working) and an "Open the conversation" button.
* **No engine available**: if your organization gave you no engine, the model menu says what to do (add your key or subscription, or ask an administrator for an engine) instead of a list reduced to "Auto".
* **"This run" panel** (computer): same column, radius and background as Environment, Context and Connectors, in light and dark.
* **No more visible identifiers**: Environment shows "This conversation's folder", and accounts, people, bots, teams, removed engines, orphan cloud computers, folders, voices, the log and server errors use readable labels. Full paths stay in tooltips only.
* **Code section**: when Perspicax refuses access to the agents API (401 or 403), the Code section disappears instead of showing "Perspicax answered 401."

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
