Sagax 0.8.122 refait la page des fournisseurs : une rangée par fournisseur, des comptes qu'on renomme sur place, la clé d'API et les modèles sur la page du fournisseur.

### Ce que tu remarques d'abord

* **La page des fournisseurs, deuxième passe (#4383)** : chaque fournisseur est maintenant une seule rangée, avec une seule ligne de résumé, et un clic ouvre sa page.
  * La page d'un fournisseur sépare les comptes, le serveur, la clé d'API, tes bots qui l'utilisent et les modèles.
  * Tu peux renommer n'importe quel compte sur place. Sur un serveur d'organisation, chaque personne nomme ses propres comptes pour elle-même, et un nom vidé revient au nom par défaut.
  * Un fournisseur connecté dont un compte est expiré le dit sur sa rangée.
  * « Ajouter une clé » marche pour tous les moteurs à clé.
  * Sur une rangée étroite, le bouton passe sous le texte.
* **Ce qui fait tourner un bot est gardé dans les données, par fournisseur (#4382)** : aucun changement visible pour l'instant. Tes bots gardent un moteur au choix à côté de leur modèle, et chaque personne a un moteur par défaut par fournisseur. Les bots existants sans choix ne changent pas.

### Ce qui reste pour une version suivante

* Les applications iPhone et iPad dessinent encore d'anciennes cartes de passage de routine dans une conversation jusqu'à la sortie de leur propre filtre.

## Avant de mettre à jour

Si tu héberges Sagax toi-même, garde une copie de tes données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.122 redoes the Providers page: one row per provider, accounts renamed in place, the API key and the models on the provider's page.

### What you notice first

* **The Providers page, second pass (#4383)**: each provider is now a single row, with a single summary line, and a click opens its page.
  * A provider's page separates the accounts, the server, the API key, your bots that use it and the models.
  * You can rename any account in place. On an organization server, each person names their own accounts for themselves, and an emptied name goes back to the default name.
  * A connected provider with an expired account says so on its row.
  * Add key works for every key engine.
  * On a narrow row, the button moves under the words.
* **What runs a bot is kept in the data, per provider (#4382)**: no visible change yet. Your bots keep an optional engine beside their model, and each person has a default engine per provider. Existing bots with no choice do not change.

### What stays for a later version

* The iPhone and iPad apps still draw old routine run cards in a conversation until their own filter ships.

## Before you update

If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
