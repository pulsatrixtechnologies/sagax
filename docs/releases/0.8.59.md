# Sagax 0.8.59

Correctif du serveur : la 0.8.58 pouvait ne pas démarrer, et la 0.8.59 règle ce problème. Le reste de la version peaufine le chat, le panneau du bot, les Réglages et les routines : les noms de fichiers dans les messages du bot sont cliquables, le panneau du bot montre une vraie vignette de l'ordinateur choisi, et l'écran de démarrage disparaît. Elle vaut pour l'app de bureau, le serveur, iPhone et iPad.

## Serveur

* Le serveur Sagax démarre de nouveau. Dans la 0.8.58, il pouvait s'arrêter dès le lancement et redémarrer en boucle. Si tu as gardé la 0.8.56 ou la 0.8.57 sur ton serveur en attendant, tu peux passer à la 0.8.59. PR #2440.
* Chaque tour de conversation part maintenant d'une racine d'exécution commune, ce qui rend le suivi des tours plus fiable. PR #2390.

## Chat

* Les noms de fichiers dans les messages du bot sont cliquables. PR #2423.
* Les marqueurs spéciaux d'un modèle (comme `<|eos|>`) ne s'affichent plus dans les réponses, peu importe le moteur. PR #2402.
* La question de passation d'un bot s'affiche dans la même feuille de questions que les autres. PR #2417.
* Le bouton GIF passe dans le menu « + » du champ de saisie. PR #2412.
* Les séparateurs de la rangée d'une exécution de routine sont simples, sans doublons. PR #2438.

## Groupes

* Un bot qui attend une réponse dans une autre conversation n'est plus affiché comme « occupé » dans un groupe. PR #2391.
* Une salle s'ouvre aux personnes qu'elle liste. PR #2419.
* Chaque personne voit seulement ses propres équipes dans la barre latérale et la carte d'équipe. PR #2442.

## Panneau du bot

* Le panneau montre une vraie vignette de l'ordinateur sélectionné. PR #2410.
* La carte d'une session de code tient sur une seule rangée. PR #2400.
* Le titre du bot s'affiche sous son nom, sans « · ». PR #2395.
* La ligne Computer est alignée avec Upcoming. PR #2388.
* Les couleurs et les contrôles d'Apparence n'apparaissent que dans la section Apparence ouverte. PR #2398.
* Les lignes de délégation prennent la forme d'une liste de sous-agents, comme dans Grok Bot. PR #2429.
* La page profil du bot est refaite : chaque section suit le style de Channels et Bot accounts, Activity regroupe les changements par jour, et deux onglets s'ajoutent, Analytique (messages, heures sauvées, usage, principaux utilisateurs) et Partage. PR #2446.

## Routines

* Le volet latéral d'une routine est réorganisé : Runs comme dans Avancé, et plus de rangées Active ni This week. PR #2424.

## Réglages

* La page App est répartie sur General, Help and about, Backups et Security. PR #2431.
* La section Backups reste cachée pour un membre qui n'a pas la permission de gérer les sauvegardes. PR #2435.

## Plugins

* La section Ce Mac utilise la même grille à deux colonnes que le reste de la page. PR #2404.

## Mac

* Sagax demande à macOS l'autorisation d'Automation sous son propre nom, et les dates de Messages se lisent correctement. PR #2414.
* Les notifications natives restent dans le Centre de notifications, et les bots n'en déclenchent plus. PR #2389.
* L'écran de démarrage est retiré : l'app s'ouvre directement. PR #2406.
* La fenêtre d'une page détachée cache son cadre jusqu'au survol ou au focus. PR #2393.

## Comptes

* Chaque lecture d'un compte de fournisseur suit maintenant le bon compte. PR #2392.

## iPad

* Parité, ronde 6 : les passes de routine s'affichent comme des messages, les onglets de groupe sont en place, et la page de modification du bot reprend son en-tête. PR #2432.
* Parité, ronde 7 : le panneau de groupe a ses onglets Bibliothèque et Tâches, le mode Coding montre la session en cours, le nom et le titre du bot se modifient sur place, et le menu du bot s'ouvre par un appui long sur son identité. PR #2445.
* Les libellés de l'app iOS reprennent ceux du bureau. PR #2448.
* Sur iOS, la rangée Voix affiche « Voix par défaut du fournisseur » au lieu de « Non défini ». PR #2451.

## Fiabilité

* Tests et contrôles de la base réparés, aucun changement visible. PR #2397, PR #2408, PR #2422, PR #2426.
* Sécurité : la dépendance minimatch est mise à jour (alerte Dependabot #45). PR #2452.

## Avant de mettre à jour

Installe cette version sur le serveur Sagax en premier : c'est elle qui corrige le démarrage de la 0.8.58. Mets ensuite à jour l'app de bureau et l'app iOS. Tes bots, modèles, équipes, plugins et réglages personnels sont conservés.

## English

Server fix: 0.8.58 could fail to start, and 0.8.59 resolves that. The rest of the version polishes the chat, the bot panel, Settings and routines: file names in bot messages are clickable, the bot panel shows a real thumbnail of the selected computer, and the startup splash screen is gone. It covers the desktop app, the server, iPhone and iPad.

### Server

* The Sagax server starts again. In 0.8.58 it could stop at launch and restart in a loop. If you kept 0.8.56 or 0.8.57 on your server in the meantime, you can move to 0.8.59. PR #2440.
* Every conversation turn now starts from a shared runtime root, which makes turn tracking more reliable. PR #2390.

### Chat

* File names in bot messages are clickable. PR #2423.
* A model's special markers (such as `<|eos|>`) no longer show up in replies, whichever engine is used. PR #2402.
* A bot's hand-off question shows in the same question sheet as the others. PR #2417.
* The GIF button moves into the composer's "+" menu. PR #2412.
* The separators on a routine run row are single, with no duplicates. PR #2438.

### Groups

* A bot waiting for an answer in another conversation is no longer shown as "busy" in a group. PR #2391.
* A room opens to the people it lists. PR #2419.
* Each person sees only their own teams in the sidebar and the team map. PR #2442.

### Bot panel

* The panel shows a real thumbnail of the selected computer. PR #2410.
* A coding session card fits on one row. PR #2400.
* The bot's title shows under its name, without "·". PR #2395.
* The Computer row lines up with Upcoming. PR #2388.
* Appearance colors and controls only show inside the open Appearance section. PR #2398.
* Delegation rows take the shape of a sub-agent list, as in Grok Bot. PR #2429.
* The bot profile page is redone: every section follows the Channels and Bot accounts style, Activity groups changes by day, and two tabs are added, Analytics (messages, hours saved, usage, top users) and Share. PR #2446.

### Routines

* A routine's side panel is reorganized: Runs as in Advanced, and no more Active or This week rows. PR #2424.

### Settings

* The App page is split across General, Help and about, Backups and Security. PR #2431.
* The Backups section stays hidden for a member without permission to manage backups. PR #2435.

### Plugins

* The This Mac section uses the same two-column grid as the rest of the page. PR #2404.

### Mac

* Sagax asks macOS for Automation permission under its own name, and Messages dates read correctly. PR #2414.
* Native notifications stay in Notification Center, and bots no longer trigger them. PR #2389.
* The startup splash screen is removed: the app opens directly. PR #2406.
* A detached page window hides its frame until hover or focus. PR #2393.

### Accounts

* Every provider-account read now follows the right account. PR #2392.

### iPad

* Parity, round 6: routine passes show as messages, group tabs are in place, and the bot edit page gets its header back. PR #2432.
* Parity, round 7: the group panel gets its Library and Tasks tabs, Coding mode shows the current session, the bot's name and title edit in place, and the bot menu opens with a long press on its identity. PR #2445.
* The iOS app's wording now matches the desktop app. PR #2448.
* On iOS, the Voice row now shows "Provider's default voice" instead of "Not set". PR #2451.

### Reliability

* Base tests and guards repaired, with no visible change. PR #2397, PR #2408, PR #2422, PR #2426.
* Security: the minimatch dependency is updated (Dependabot alert #45). PR #2452.

### Before you update

Install this version on the Sagax server first: it fixes the 0.8.58 startup problem. Then update the desktop app and the iOS app. Your bots, models, teams, plugins and personal settings are kept.
