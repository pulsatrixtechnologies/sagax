# Sagax 0.8.34

Une restauration redonne toutes vos skills, les installations touchées depuis 0.8.24 retrouvent les leurs d'elles-mêmes, les sauvegardes emportent l'index de la bibliothèque de skills de l'organisation, et une skill installée pour un seul bot reste à ce bot.

### Skills

* Après la restauration d'un espace de travail, chaque skill d'un bot répond de nouveau, au lieu de « introuvable » : un bot lit la copie de la bibliothèque qui lui est assignée quand il n'a pas sa propre copie.
* Les installations mises à jour entre 0.8.24 et 0.8.33 retrouvent d'elles-mêmes les skills de la bibliothèque qui ne figuraient plus dans son index, au premier démarrage de 0.8.34. Seule une skill dont le fichier est intact est reprise, et une skill déjà présente n'est jamais remplacée.
* Une skill installée pour « Ce bot » reste privée à ce bot après un redémarrage ou une restauration, au lieu de passer dans la bibliothèque de l'organisation.

### Sauvegardes

* Une sauvegarde emporte maintenant l'index de la bibliothèque de skills de l'organisation (les entrées seulement, jamais un secret ni les serveurs MCP), vérifié à la restauration. Les skills de la bibliothèque restaurées sont listées, lisibles et assignées aux mêmes bots qu'avant.
* Une sauvegarde faite avec 0.8.33 ou avant se restaure comme avant.

### Interne

* Le format du fichier .sagaxbackup est documenté, et la vérification des sauvegardes couvre les skills de la bibliothèque restaurées dans une installation neuve.

## Avant de mettre à jour

Rien à préparer à la main pour 0.8.34. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English
<!-- date: 2026-11-03 -->
A restore gives back every skill, installs affected since 0.8.24 recover theirs by themselves, backups carry the organization skills library index, and a skill installed for one bot stays with that bot.

### Skills

* After a workspace restore, every skill of a bot answers again, instead of "not found": a bot reads the library copy assigned to it when it has no copy of its own.
* Installs updated between 0.8.24 and 0.8.33 recover by themselves the library skills that had dropped out of its index, on the first start of 0.8.34. Only a skill whose file is intact is taken back, and a skill already there is never replaced.
* A skill installed for "This bot" stays private to that bot after a restart or a restore, instead of moving into the organization library.

### Backups

* A backup now carries the organization skills library index (the entries only, never a secret or the MCP servers), checked on restore. Restored library skills are listed, readable and assigned to the same bots as before.
* A backup made with 0.8.33 or earlier restores as before.

### Internal

* The .sagaxbackup file format is documented, and the backup verification covers library skills restored into a fresh install.

## Before you update

Nothing to prepare by hand for 0.8.34. If you self-host Sagax, keep a copy of your data (`docs/self-hosting.md`) before replacing the image or the binary.
