Sagax 0.8.84 permet à un bot d'appeler un connecteur peu importe son modèle, fait de /feedback la seule façon d'envoyer un commentaire, et remplit la fenêtre avec la vue de l'ordinateur.

### Ce que tu remarques d'abord

* **Connecteurs sur tous les moteurs** : un bot appelle un connecteur quel que soit son modèle. Un seul point d'accès pour les connecteurs, un seul verdict et une seule clé de règle sur chaque moteur, des hôtes de connecteurs pour trois moteurs, et une seule liste de connecteurs dans les consignes du bot.
* **/feedback, la seule porte** : il n'y a plus de bot Commentaires ni de bouton dans la barre latérale. La commande /feedback envoie des rapports précis et anonymisés.
* **Vue de l'ordinateur** : elle remplit toute la fenêtre de l'application, avec des points d'activité pendant que l'ordinateur démarre.
* **Veilles Pulsatrix éteintes pour l'instant** : elles réveillaient tous les bots. Un seul bot par personne réagit maintenant à une veille, et les veilles restent éteintes pour chaque bot jusqu'à ce que chaque personne puisse choisir ce qu'elle reçoit.

### Autres correctifs

* **Rôles d'agents de plugins** : ils démarrent maintenant à partir d'un tour de bot.
* **Serveurs GitHub de plugins** : ils portent la connexion GitHub de la personne, fini l'erreur HTTP 400 à la connexion.
* **Ordinateur hôte** : une seule session par personne et par hôte, renouvelée quand elle se termine, et plus de réponse muette avec le code de sortie 0.
* **Profil du bot** : chaque changement d'une sous-page s'applique sur place.
* **Tests du proxy des agents** : ils sont de nouveau verts, avec une vérification rapide quand les outils changent.
* **Textes des outils** : ils décrivent un seul chat et sans tirets.
* **Consigne de style de travail** : elle repasse sous sa limite de longueur.

## Avant de mettre à jour

Rien à préparer à la main pour 0.8.84. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.84 lets a bot call a connector whatever its model, makes /feedback the one way to send feedback, and fills the app window with the desktop view.

### What you notice first

* **Connectors on every engine**: a bot calls a connector whatever its model. One connector hub, one verdict and one rule key on every engine, connector hosts for three engines, and one connector list in the bot's prompt.
* **/feedback, the one way in**: there is no Feedback bot and no sidebar button any more. The /feedback command files precise, anonymized reports.
* **Desktop view**: it fills the whole app window, with activity dots while the computer starts.
* **Pulsatrix watches are off for now**: they were waking every bot. Only one bot per person now reacts to a watch, and the watches stay off for every bot until each person can choose what they receive.

### Other fixes

* **Plugin agent roles**: they now start from a bot turn.
* **Plugin GitHub servers**: they carry the person's GitHub connection, so no more HTTP 400 at connection.
* **Host computer**: one session per person and host, renewed after it ends, and no more silent answer with exit code 0.
* **Bot profile**: each sub-page change applies in place.
* **Agents proxy tests**: they are green again, with a fast check when tools change.
* **Tool texts**: they describe one chat and drop dashes.
* **Work-style prompt**: it is back under its length cap.

## Before updating

Nothing to prepare by hand for 0.8.84. If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before replacing the image or the binary.
