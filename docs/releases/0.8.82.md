Sagax 0.8.82 donne aux bots plus de liberté entre eux : un bot joint maintenant tous les bots de la même personne, peu importe la section, et peut en créer beaucoup plus. Les envois entre bots s'affichent aussi plus calmement dans le chat.

### Équipe de bots

* **Tous les bots de la même personne** : un bot peut écrire à n'importe quel bot de la même personne, quelle que soit la section où il se trouve, et jamais à ceux d'une autre personne.
* **Plus de bots créés par des bots** : la limite par heure passe de 6 à 50, et le nombre de bots créés en un seul tour passe de 4 à 15.

### Chat

* **Ligne « Message envoyé »** : les envois d'un tour vers d'autres bots forment une seule ligne discrète et centrée, visible même quand les appels d'outils sont masqués. Les noms sont neutres et le texte est traduit, y compris un envoi échoué.

### Connexion et langue

* **Version sur la page de connexion** : la page de connexion affiche la version du produit.
* **Bloc de code** : le nombre de lignes d'un bloc de code est maintenant traduit.
* **Tutoiement** : le français écrit par le serveur tutoie maintenant.

## Avant de mettre à jour

Rien à préparer à la main pour 0.8.82. Si vous hébergez Sagax vous-même, gardez une copie de vos données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.82 gives bots more freedom with each other: a bot now reaches every bot of the same person whatever the section, and can create many more. Sends between bots also show more quietly in the chat.

### Bot team

* **Every bot of the same person**: a bot can write to any bot of the same person, whatever section it sits in, and never to another person's bots.
* **More bots made by bots**: the hourly limit goes from 6 to 50, and the number of bots created in a single turn goes from 4 to 15.

### Chat

* **"Messaged" line**: a turn's sends to other bots form one quiet, centered line, visible even when tool calls are hidden. Names are neutral and the text is translated, including a failed send.

### Sign-in and language

* **Version on the sign-in page**: the sign-in page shows the product version.
* **Code block**: the line count of a code block is now translated.
* **Informal French**: French written by the server now uses "tu".

## Before updating

Nothing to prepare by hand for 0.8.82. If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before replacing the image or the binary.
