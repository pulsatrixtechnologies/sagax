Sagax 0.7.7 corrige la confidentialite de l'ecran Utilisation et ajoute un guide de demarrage de dix minutes pour les MSP.

## Confidentialite

* **Traces d'utilisation par personne** : dans Reglages > Utilisation, chaque personne connectee voit maintenant ses propres jobs seulement (ou son temps et son argent sont passes), jamais ceux d'une autre personne. Avant, cet ecran personnel montrait les traces de tout le ledger : un membre ordinaire n'y voyait rien, et un administrateur y voyait les jobs de tout le monde. On reutilise le ledger existant ; aucun contenu de message, aucun secret et aucun UUID ne sont affiches.

## Documentation

* **Demarrage MSP en dix minutes** : un guide pas a pas accompagne une equipe MSP de l'installation a son premier message, sans detour.

## Installation

**macOS** (Apple Silicon : `arm64`, Intel : `x64`) : ouvrez `Sagax-0.7.7-arm64.dmg` ou `Sagax-0.7.7-x64.dmg` et glissez Sagax dans Applications. Signee (Developer ID) et notariee par Apple.

**Windows** (x64 et arm64) : lancez `Sagax-0.7.7-setup.exe`. Non signe : SmartScreen affiche un editeur inconnu ; choisissez **Informations complementaires**, puis **Executer quand meme**. Versions portables : `Sagax-0.7.7-win-x64.zip` et `Sagax-0.7.7-win-arm64.zip`.

## English

Sagax 0.7.7 fixes the privacy of the Usage screen and adds a ten-minute getting-started guide for MSPs.

* **Per-person usage traces**: in Settings > Usage, each signed-in person now sees only their own jobs (where their time and money went), never someone else's. Before, this personal screen showed traces for the whole ledger: an ordinary member saw nothing there, and an administrator saw everyone's jobs. It reuses the existing ledger; no message content, no secret and no UUID is shown.
* **Ten-minute MSP quickstart**: a step-by-step guide takes an MSP team from install to its first message, with no detour.

macOS builds are signed with a Developer ID and notarized by Apple. Windows (x64 and arm64, one installer) is unsigned: SmartScreen shows an unknown publisher; choose More info, then Run anyway.
