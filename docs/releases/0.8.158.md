Sagax 0.8.158 remplace la longue liste de modèles du compositeur par cinq modes, et corrige les appels vocaux : démarrage à froid, nombre de processus et moteur de secours.

### Ce que tu remarques d'abord

* **Le bouton de modèle du compositeur ouvre cinq modes** : Auto, Fast, Expert, Heavy et Build. Le bouton affiche le nom du mode.
* **Les appels vocaux démarrent correctement** et, quand un moteur refuse avec une erreur 403, le moteur de secours répond vraiment.

### Compositeur

* **Sélecteur de mode : Auto, Fast, Expert, Heavy, Build (#4906)** : à chaque tour, Sagax associe chaque mode aux meilleurs modèles que tu peux utiliser (fournisseurs et comptes connectés, modèles locaux compris). Une infobulle à côté du menu dit ce que fait le mode, puis le modèle derrière (« Quick responses · Grok 4.7 »). « Tous les modèles », au bas du menu, ouvre la fenêtre des modèles (moteurs, modèles, effort, favoris, réglages) : rien n'a été retiré, c'est à une étape de plus.
  * **Fast** : ton propre modèle rapide, sinon le plus rapide des bons modèles, effort bas.
  * **Expert** : le modèle le plus fort du fournisseur le plus fort, effort élevé.
  * **Build** : d'abord un modèle fait pour le code, sinon le plus fort des modèles de code.
  * **Heavy** : une équipe d'agents avec un Leader. Le modèle d'Expert dirige, et l'équipe est composée du meilleur modèle de chaque fournisseur (avec un seul fournisseur, plusieurs agents sur son modèle le plus fort). L'exécution de l'équipe et le panneau Thoughts arrivent dans la prochaine version.
  * Un mode qu'aucun modèle ne peut servir est masqué. Sans rien à exécuter, il revient sur Auto.
  * Le mode choisi est conservé après un redémarrage, et un tour d'appel prend le même choix qu'un tour écrit.
* **Auto trouve maintenant le meilleur modèle de Google** : les identifiants « -pro » étaient pris pour des variantes et écartés dès que Flash était listé.

### Appels vocaux

* **Démarrage à froid corrigé (#4907)** : le premier tour d'un appel n'est plus marqué par le préchauffage de l'appel.
* **Plus de troisième processus de moteur (#4907)** : un nouvel appel sur la conversation attend le préchauffage précédent au lieu de l'interrompre.
* **Le moteur de secours répond vraiment après un 403 (#4907)** : le tour refusé est renvoyé une fois au moteur de secours choisi, la conversation garde son modèle, et le message suivant démarre sur le secours.

### Interne

* **Nettoyage de l'ancien choix du modèle rapide (#4907)** : code mort et tests retirés.

## Avant de mettre à jour

Si tu héberges Sagax toi-même, garde une copie de tes données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.158 replaces the long model list in the composer with five modes, and fixes voice calls: cold start, process count and the backup engine.

### What you notice first

* **The composer's model button opens five modes**: Auto, Fast, Expert, Heavy and Build. The button shows the mode name.
* **Voice calls start correctly**, and when an engine refuses with a 403 error, the backup engine really answers.

### Composer

* **Mode picker: Auto, Fast, Expert, Heavy, Build (#4906)**: every turn, Sagax maps each mode to the best models you can use (connected providers and accounts, local models included). A tooltip beside the menu says what the mode does, then the model behind it ("Quick responses · Grok 4.7"). "All models" at the foot of the menu opens the models window (engines, models, effort, favorites, switches): nothing was removed, it is one step further away.
  * **Fast**: your own fast model, else the quickest good model, effort low.
  * **Expert**: the strongest model of the strongest provider, effort high.
  * **Build**: a model made for code first, else the strongest coding-tier model.
  * **Heavy**: a team of agents with a Leader. Expert's model leads, and the team is composed of the best model of each provider (with one provider, several agents on its strongest model). The team run and the Thoughts panel arrive in the next version.
  * A mode no model can serve is hidden. With nothing to run it falls back on Auto.
  * The chosen mode survives a restart, and a call turn takes the same pick as a typed turn.
* **Auto now finds Google's best model**: "-pro" ids were taken for variants and dropped whenever Flash was listed.

### Voice calls

* **Cold start fixed (#4907)**: the first turn of a call is no longer marked by the call's warm-up.
* **No third engine process (#4907)**: a new call on the conversation waits for the previous warm-up instead of aborting it.
* **The backup engine really answers after a 403 (#4907)**: the refused turn is resent once to the chosen backup, the conversation keeps its model, and the next message starts on the backup.

### Internal

* **Cleanup of the old fast-model pick (#4907)**: dead code and tests removed.

## Before you update

If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
