Sagax 0.8.126 range la page d'un fournisseur : une rangée par connexion, une seule façon de se connecter, et tu peux retirer un compte.

### Ce que tu remarques d'abord

* **Une rangée par connexion (#4425)** : dans la section Comptes d'un fournisseur, une connexion est une rangée, et le compte de la liste suit.
  * Sur un serveur d'organisation, Codex et le forfait ChatGPT lisent la même connexion : ils forment maintenant une seule rangée.
  * Chaque rangée dit son état et offre un seul geste pour se connecter ou se déconnecter. Les anciens blocs par moteur ne sont plus dessinés dans une rangée de compte. La deuxième connexion de Grok a sa propre rangée.
* **Une seule façon de se connecter, pour tous les fournisseurs** : le bouton de la rangée devient l'état de la connexion, avec un Annuler discret.
  * Sous la rangée, une courte phrase donne l'heure d'expiration, puis le code de l'appareil et la page de connexion, ou le champ du code et Terminer.
  * Le même parcours sert aussi pour la reconnexion sous l'usage du forfait, la mise en place d'un moteur de l'organisation, la première configuration et un clavardage qui a besoin d'un moteur. Un code refusé est dit pendant que l'étape reste ouverte.
* **Retirer un compte ajouté à côté du premier (#4425)** : pour tous les fournisseurs, avec la même confirmation que pour une clé.
  * Sur un serveur seul, le compte part du serveur. Sur un serveur d'organisation, il part de ta liste et sa connexion avec lui.
  * Si des bots utilisent encore le compte, le refus les nomme.

### Ce qui reste pour une version suivante

* Les applications iPhone et iPad dessinent encore d'anciennes cartes de passage de routine dans une conversation jusqu'à la sortie de leur propre filtre.

## Avant de mettre à jour

Si tu héberges Sagax toi-même, garde une copie de tes données (`docs/self-hosting.md`) avant de remplacer l'image ou le binaire.

## English

Sagax 0.8.126 tidies a provider's page: one row per sign-in, one way to sign in, and you can remove an account.

### What you notice first

* **One row per sign-in (#4425)**: in a provider's Accounts section, one sign-in is one row, and the list's count follows.
  * On an organization server, Codex and the ChatGPT plan read the same sign-in: they now form one row.
  * Each row says its state and offers a single way to sign in or out. The older per-engine blocks are no longer drawn in an account row. Grok's second sign-in has a row of its own.
* **One way to sign in, for every provider**: the row's button becomes the sign-in's state, with a quiet Cancel.
  * Under the row, one short sentence gives the expiry, then the device code and the sign-in page, or the code field and Finish.
  * The same flow serves the reconnect under the plan's usage, the organization's engine setup, onboarding and a chat that needs an engine. A refused code is said while the step stays open.
* **Remove an account added beside the first one (#4425)**: for every provider, with the same confirmation as for a key.
  * On a solo server the account leaves the server. On an organization server it leaves your list and its sign-in goes with it.
  * If bots still use the account, the refusal names them.

### What stays for a later version

* The iPhone and iPad apps still draw old routine run cards in a conversation until their own filter ships.

## Before you update

If you host Sagax yourself, keep a copy of your data (`docs/self-hosting.md`) before you replace the image or the binary.
